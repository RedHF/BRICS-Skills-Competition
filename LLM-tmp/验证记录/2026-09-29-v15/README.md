# v15 生图拓印榫卯版

使用用户指定的 Qwen Image 3.0 兼容 API 生成宣纸、毛笔、朱印、淡色提示牌、木梁榫件、戏台构件、技艺展品和图式卡。原始图与提示词保存在 `output/imagegen/v15/`；`tools/process_puzzle_art.py` 裁切图集、制作透明贴图，并依据服务端原有笔画路径，用生成的枯笔纹理制成五套字样。素材位于 `LLM-tmp/客户端/assets/puzzles/`。未使用 Codex 内置生图，一次性密钥未写入仓库。

拓印界面现在有宣纸、字样、青色起笔印、朱色收笔印及跟随指针的毛笔。按用户后续反馈，玩家绘制轨迹保留原来的黑线，失败时仍显示红线；笔画坐标、容差和服务端判定没有改变。提示牌以低透明度显示，避免压过宣纸。

榫卯改用生成的梁、榫件和榫口；戏台两步使用单独的踏步、栏板和织锦素材。技艺展示、牌坊和戏曲图式选择也换成素材。自检后，探索场景的调查标记、摇杆及侵蚀裂纹改用现有／生成贴图；保留用于状态表达的血条、遮罩和上述用户指定黑线。

验证：Godot 导入无脚本错误；`tests/puzzle_art_review.gd` 20 项通过，覆盖五套拓印字样、毛笔跟手、榫卯拖动吸附及各界面截图；`tests/playability.gd` 278 项通过、失败 0。截图位于本目录。正式 Windows EXE 冒烟测试通过，服务自动启停、退出码 0，发行审计无缺失或额外文件，7 项清单哈希一致；见 `release-verification.json`。
