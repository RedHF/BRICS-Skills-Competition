# v16 音画交互版

按钮通用点击音从原来的单频短音改为轻木印的噪声与低频共鸣；进入关卡、翻看往事等操作使用翻页声，毛笔触纸有单独的短促沙沙声。素材由 `tools/generate_interaction_audio.py` 以固定种子生成，位于 `LLM-tmp/客户端/assets/audio/`。描字环节使用新制的 48 秒五声调式低音量循环配乐，离开时与主题音乐交叉淡出，战斗音乐仍单独切换。

玩家点击进入关卡和完成关卡结算时，画面用深墨色遮罩渐暗后再渐亮。通用按钮、图式卡、重访选项及对话按钮在鼠标悬浮时轻微放大提亮，移开时复位；通用按钮的键盘焦点也有相同反馈。v15 的宣纸、朱印、木梁榫件及用户指定的黑色落笔轨迹均保留。

验证：Godot 导入无脚本错误；拓印与交互专项 37 项、完整可玩性回归 278 项均通过。深色过渡截图见本目录的 `transition-dark.png`。发行版以 `tests/release_smoke.gd` 核对四张音频、配乐切换、按钮悬浮、渐暗渐亮及前版生成素材。真实 EXE 退出码 0，服务自动启停，7 项清单哈希一致；见 `release-verification.json` 与 `console.log`。
