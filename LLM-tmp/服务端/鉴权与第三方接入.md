# 账号与鉴权（内容协议 5 / JSON 存档版本 2）

用户名密码注册、登录后，服务端返回 `access_token`、`expires_at` 和当前 `player`。游戏接口必须携带 `Authorization: Bearer <access_token>`；玩家 ID 只是资源标识，不能当作登录凭证。账号和新玩家在一个 JSON 事务中创建。

| 接口 | 请求 | 结果 |
|---|---|---|
| POST `/api/v1/auth/register` | `{username,password}` | 注册并登录 |
| POST `/api/v1/auth/login` | `{username,password}` | 校验密码并登录 |
| GET `/api/v1/auth/me` | Bearer 令牌 | 当前玩家 |
| POST `/api/v1/auth/logout` | Bearer 令牌 | 撤销当前令牌 |
| GET `/api/v1/auth/providers` | 无 | 已注册的第三方服务端适配器名称 |
| POST `/api/v1/auth/external` | `{provider,credential}` | 验证平台凭证并登录 |

除健康检查和登录入口外，目录、存档、账册、事件及兼容别名均要求鉴权。服务端核对玩家及事件会话归属；没有登录为 401，跨账号访问为 403。旧 `POST /players` 仅能读取或修改当前账号的显示名，不能再认领任意玩家。

用户名忽略首尾空格和大小写，允许 3–24 个 Unicode 字母、数字或下划线；密码为 8–72 字节。密码使用 bcrypt cost 12，并由库生成随机盐，不保存明文。登录入口按连接来源 IP 限制每分钟 20 次请求，不信任客户端 `X-Forwarded-For`。外部部署可在网关按客户端 IP 进一步限流。

令牌为 32 字节密码学随机值，服务端内存只保存其 SHA256、玩家 ID 和 24 小时有效期；退出立即撤销，服务重启后需要重新登录。客户端不落盘保存密码或令牌。本地服务默认仅监听 `127.0.0.1:8090`；连接远程服务必须配置 HTTPS，客户端禁止 API 重定向，防止凭证转发到其他地址。

按用户要求，已清除旧匿名进度和身份文件。版本 1 存档不会被自动认领或静默迁移；新增账号从独立空进度开始。正式交付不带测试账号。

## 第三方 SDK 接入位置

当前没有指定第三方平台，因此发行包不显示可用的第三方平台按钮。这里保留的是经过测试的接入契约，不包含微信、Steam 等平台的实际 SDK、应用密钥或平台审核配置。

服务端在 `internal/httpapi/auth.go` 定义：

```go
type IdentityProvider interface {
    Name() string
    VerifyCredential(context.Context, string) (ExternalIdentity, error)
}
type ExternalIdentity struct { Subject, DisplayName string }
```

平台适配器使用官方 SDK 或官方验证 API 验证一次性授权码/登录票据，核对签名、签发方、应用 ID（audience）、有效期及平台规定的 nonce/state。验证成功才返回稳定的 Subject；不能直接信任客户端传来的用户 ID。凭证无效返回 `httpapi.ErrInvalidCredential`，服务或 SDK 故障返回实际错误，接口分别返回 401 或 502。

在 `cmd/server/main.go` 初始化时，将适配器传入 `httpapi.New(catalog, database, adapter)`。平台密钥只放服务端。账号使用平台名称和 Subject 联合标识，同一平台重复登录复用玩家，不同平台的相同 Subject 不会混用账号；不会按相同昵称自动合并。

客户端 SDK 节点连接 `main.gd` 的 `third_party_login_requested(provider)` 信号，在用户点击对应平台按钮后打开平台登录。获取平台凭证后调用 `await main.login_external(provider, credential)`，再由服务端完成身份校验。用户已通过其他方式进入游戏后，迟到的 SDK 回调不会覆盖当前账号。取消或 SDK 报错时由适配器在登录页面显示明确结果。

`auth_test.go` 使用测试适配器验证凭证拒绝、重复平台登录、平台命名空间隔离及统一令牌签发；这些测试适配器不注册到发行服务端。
