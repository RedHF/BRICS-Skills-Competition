# 《檐下千秋》剧情任务与对话脚本

版本：2026-09-12 / 内容协议 v7。本文对应可运行目录 `服务端/content/chapters.json`；旧《章节叙事脚本》保留为策划过程，冲突处以本文与 v7 为准。

## 叙事与交互约定

玩家是一位在廊桥醒来的拓印师，失去了自己的名字。古建以记忆中的声音回应他；“客声”“童声”“师父回声”均为建筑保存的往事，不另加可移动 NPC。剧情的核心疑问是：保存文化，究竟是在保存完美的物，还是让活着的人继续回应它？

任务顺序为开场对话 → 三处调查 → 修复谜题 → 墨灵显影与取舍 → 守护战（如有） → 结语 → 下一任务。每关六句开场对话，三条现场线索；谜题答案在对应线索或对话中给出，结尾价值选择无错误答案。

对话支持上一句、下一句、跳过、返回及阅读位置保存。跳过只略过文字，不能获得修复奖励或跳过关卡。地图和“剧情 · 任务”显示当前目标；完成的事件加入剧情回顾，回顾不重新发奖。回顾结语保留该次取舍与终章回答；查看心舍或剧情册时，正在进行的描摹与战斗暂停，返回继续。

本次新增对话为文字演出，现有回声音频仍播放墨灵摘要，并非所有新台词均有配音。

## 任务范围与资源约定

可运行剧情为五章十任务：序章 1 任务、社庙 3 任务、戏楼 2 任务、牌坊 2 任务、通天塔 2 任务。每个任务均有六句开场对白、三条调查线索、修复步骤、取舍回应和结语；终章三种回答均可完成，不设登录门槛。每个任务的拓印图绑定 `客户端/assets/rubbings/*.png` 中的独立静态文件，缺图时显示“待装裱”。图片在发布前离线生成，运行时不调用 image2.5 或实时生成。

## 序章·风雨廊桥

### 1. 桥上平安

任务 ID：`prologue/prologue_bridge`。场景：风雨廊桥。奖励：檐·平安。完成修复与抉择后进入守护战。

开场对话：

1. **檐下谱**：雨停了。你醒在桥心，手中只有一本空白册子，封底写着：请把故事交还给愿意听的人。

2. **拓印师**：我的名字也被雨洗掉了吗？

3. **廊桥**：名字可以慢慢找。先帮我记住两个字——平安。桥栏已经快认不出回家的脚步了。

4. **拓印师**：只要把字重新写上，你就会好起来？

5. **廊桥**：字是门，走过这里的人才是屋里的灯。去看看断檐、桥心和桥栏，你会知道该留下什么。

6. **拓印师**：好。我先听你说完，再落笔。

调查线索：

- 断裂廊檐：断檐下面留着一块干燥的地方。桥曾替赶路的人遮雨，而不仅是让他们过河。

- 桥心刻字：刻痕里压着许多细小补笔。‘平安’不是一人写成，而是一代代行人续上的祝愿。

- 半蚀桥栏：桥栏磨出了孩子手掌的高度。送别的人总在这里等，直到远处有人挥手。

修复步骤：

- 沿完整墨线拓印桥心刻字。（沿笔画描摹，允许单笔重描）

记住后的回应：廊桥：你记住的不是我的年岁，是有人盼着归来。斗拱的力，借你撑下一程。

抹去旧记忆后的回应：廊桥：你也许忘了谁曾在这里等候，但学会的守护还留在手里。

守护前对白：廊桥：白蚀正扑向刚显影的刻字。别急，先用斗拱承住，再挥墨驱散它。

任务结语：你把‘平安’收入檐下谱，桥栏重新染上旧木的暖色。雾后露出一条山路，路尽头的社庙正传来细弱的咳声。

## 第一章·社庙

### 2. 香火断

任务 ID：`temple/temple_incense`。场景：社庙正殿。奖励：社·承香。完成修复与抉择后进入守护战。

开场对话：

1. **檐下谱**：社庙正殿的主梁悬在半空。梁下并排放着几只大小不同的旧碗。

2. **社庙**：他们凑不出一根好木头，就把各家的余料抬来。那年春社，屋顶总算没有漏雨。

3. **拓印师**：我以为你记着的是香火。

4. **社庙**：也记着。可香下面，是来修屋顶的人。别只擦亮香炉，抬头看看梁。

5. **拓印师**：榫口还在，按左、中、右的承重点归位，就能撑起来。

6. **社庙**：替我把这份齐心记住。香可以再点，肯一起动手的人不该被忘掉。

调查线索：

- 倾倒香炉：倾倒香炉下有一圈新旧不同的灰。有人在村子渐空后仍回来看过。

- 主梁榫口：三道榫口由浅至深分布：先左、再中、最后右。受力靠咬合，而不靠把木头硬钉在一起。

- 供桌记号：供桌背面刻着捐木、送饭、搬石的记号，没有哪一笔比另一笔更大。

修复步骤：

- 将左燕尾榫放入主梁榫口。（解法：left）

- 将承重斗放入主梁中央。（解法：center）

- 将右燕尾榫归位。（解法：right）

记住后的回应：社庙：承住一座屋的，从来不只一根梁。你愿意记住他们，香就没有断。

抹去旧记忆后的回应：社庙：谱页腾出了位置。被放下的人仍曾来过，账册会替你记下这次取舍。

守护前对白：社庙：梁刚稳住，白蚀还在拉扯榫口。用斗拱守住承重点。

任务结语：三块构件依次扣合，悬梁终于落稳。你没有凭空点起香火，只扶正了香炉。侧厢忽然传来一句：饭凉了，也请进来坐。

### 3. 檐下客

任务 ID：`temple/temple_guest`。场景：社庙侧厢。奖励：社·宁安。本任务不含战斗。

开场对话：

1. **檐下谱**：侧厢门楣缺了一个字，只剩‘□安’。半碗冷饭旁叠着一件补过的蓑衣。

2. **社庙·客声**：那夜我浑身是雨，不敢跨过门槛。他却先把碗推了过来。

3. **拓印师**：他认得你吗？

4. **社庙·客声**：不认得。庙祝说，先让人安下心，才问他从哪里来。

5. **拓印师**：不是热闹的平安，是让陌生人也能宁静下来。缺的是‘宁’。

6. **社庙**：把它拓好吧。以后谁路过，都该知道这道门没有关。

调查线索：

- 半碗冷饭：旧碗边有两双筷子的磨痕。那碗饭曾被分成两份。

- 旧蓑衣：蓑衣补丁缝得很密，却没有留下主人的名字。这里的照料不以相识为条件。

- 残缺门楣：门内残纸写着‘心宁而后身安’。缺字的答案就在待客的心意里。

修复步骤：

- ‘□安’缺少哪个字？（解法：宁）

- 沿‘宁安’的墨线完成拓印。（沿笔画描摹，允许单笔重描）

记住后的回应：社庙·客声：记住这一点暖，就够我走过后来的长路。藻井的清明交给你。

抹去旧记忆后的回应：社庙·客声：你不再记得我的声音，也别忘了在别人淋雨时留一处屋檐。

任务结语：‘宁安’回到门楣，冷饭的记忆升起一点温热。前坪有孩子敲着空碗喊：开社啦——可回应他的鼓声，迟迟没有响起。

### 4. 社鼓声

任务 ID：`temple/temple_drum`。场景：社庙前坪。奖励：社·回春。完成修复与抉择后进入守护战。

开场对话：

1. **檐下谱**：前坪的社鼓蒙着白斑。槌柄上缠着一截褪色红绳，树下有深浅不同的脚印。

2. **社庙·童声**：大家说我太小，敲不响鼓。我就在边上数：一、二、三！

3. **拓印师**：你等的是春天，还是一起回来的人？

4. **社庙·童声**：都有。鼓一响，卖糖的、唱戏的、在外做工的，就都挤进院子了。

5. **社庙**：白蚀遮住了纹样。先用藻井洗去灰白，再沿旧墨线拓印。

6. **拓印师**：这回不用等谁来敲第一下。我们一起。

调查线索：

- 社鼓纹样：鼓面白斑下面藏着回旋纹，说明纹样仍在，先净化才能看清。

- 红绳鼓槌：红绳打成三个结，孩子曾用它记鼓点，也记归来的人数。

- 树下脚印：树下的旧脚印绕鼓成圈。春社是人重新相聚的日子。

修复步骤：

- 使用藻井净化鼓面白蚀斑。（解法：藻井）

- 沿显影出的鼓纹完成拓印。（沿笔画描摹，允许单笔重描）

记住后的回应：社庙·童声：听见了吗？这一次，我也敲响了！

抹去旧记忆后的回应：社庙：新鼓声响起，旧声音渐远。你失去一段私人的回声，却没有失去继续守护的手艺。

守护前对白：社庙：鼓声把白蚀引来了。施展藻井净化，再用挥墨护住鼓面。

任务结语：鼓声越过空院，枝头红绳轻晃。檐下谱多展开一格，心舍可以容纳六道记忆。远处戏楼以一声锣响回应，仿佛有人终于等到开场。

## 第二章·戏楼

### 5. 开场锣

任务 ID：`opera/opera_opening`。场景：戏楼后台。奖励：戏·行腔。完成修复与抉择后进入守护战。

开场对话：

1. **檐下谱**：戏楼里只亮着一盏台灯。水袖从行头箱垂下，锣鼓声总少了半拍。

2. **戏楼**：台上的人以为没人来了，不肯开嗓。台下的人以为不开戏了，也不肯落座。

3. **拓印师**：总得有人先开口。

4. **戏楼·旦角回声**：我是旦角，不是箱上那块褪色的标签。先替我找回水袖，再把唱腔里的行墨拓下来。

5. **拓印师**：你最想唱给谁听？

6. **戏楼·旦角回声**：唱给愿意停下的人。哪怕台下只有一人，这一声也该完整。

调查线索：

- 水袖戏单：水袖柔长，旁边的戏单还辨得‘旦’字。角色线索来自行头与戏单。

- 开场旧锣：锣边磨出一个小小缺口，许多代开场都敲在同一处。

- 台口墨线：台口记着一段起落墨线，唱腔虽散，行腔的节奏还在。

修复步骤：

- 水袖与凤冠属于哪个行当？（解法：旦）

- 沿锣面纹样拓印开场节拍。（沿笔画描摹，允许单笔重描）

记住后的回应：戏楼：飞檐把一口气送得更远。接住它，也替台下的人留一个座位。

抹去旧记忆后的回应：戏楼：你放下了旧回声。没有人能独自装下整座戏楼，唱过的这一声会留在账册。

守护前对白：戏楼：白蚀吞掉了台口的回声。施展飞檐破开灰幕，再让唱腔回到台上。

任务结语：开场锣终于落在完整的一拍上。你抬头看见二楼空座间浮出一点灯火，后台的旧戏服却轻轻落泪：还有半句绝唱，没人敢接。

### 6. 名角儿

任务 ID：`opera/opera_master`。场景：戏楼舞台。奖励：戏·绝唱。完成修复与抉择后进入守护战。

开场对话：

1. **檐下谱**：后台并排放着一双大戏鞋和一双小戏鞋。布景散落，旧戏服仍朝着台口。

2. **戏楼·师父回声**：他们只想记住我最响亮的一声，却不肯留下孩子唱错的那一句。

3. **拓印师**：因为那句不够好听？

4. **戏楼·师父回声**：可我把最后一口气，用来教他接下一句。若只剩我的绝唱，这门手艺便到我为止。

5. **拓印师**：我会把梅字台步与中央布景归好，也记住那个还在学的人。

6. **戏楼**：谱页有限，抉择会痛。但别把‘不完美’误认成‘不值得’。

调查线索：

- 梅字台步：师父在地上画了一枝梅，弟子的台步总从‘梅’位起。

- 中央布景：中央布景留出一扇门，让后来的人可以登台。

- 弟子戏鞋：小戏鞋边的墨迹被改过许多次。练习的痕迹也是传承的一部分。

修复步骤：

- 将第一步落在正确的台步点。（解法：梅）

- 将水袖纹布景板对齐。（解法：中）

记住后的回应：戏楼·师父回声：别替他唱完。听他慢慢学，会有他自己的声音。

抹去旧记忆后的回应：戏楼：一页旧声退去了。你亲手做过的选择，比一张无瑕的谱更需要被诚实记下。

守护前对白：戏楼：护住通向后台的门。用飞檐驱散白蚀，给后来的人留出登台的位置。

任务结语：你没有让绝唱永远循环，而是替它接上了一句尚显稚嫩的新声。通往石牌坊的门打开了，门后有人问：一座留名的坊，为什么没有匠人的名字？

## 第三章·牌坊

### 7. 四柱三间

任务 ID：`archway/archway_form`。场景：官道牌坊。奖励：坊·无名。完成修复与抉择后进入守护战。

开场对话：

1. **檐下谱**：牌坊横跨旧道，碑额上的名字十分清楚，柱脚的凿痕却几乎消失。

2. **牌坊**：路过的人总仰头念名字，很少低头看我怎么站着。

3. **拓印师**：四根柱子，三处开间。把中央构件归位，重量才传得到两侧。

4. **牌坊**：你看见规制了。再往下看，石脚背面有一排没有署名的手印。

5. **拓印师**：建造它的人，为什么没有自己的位置？

6. **牌坊**：也许他们没来得及写。也许有人觉得不必写。你可以从今天开始读。

调查线索：

- 四柱三间：柱脚完整保存四个承重点，中间形成三个通道，对应四柱三间。

- 中央榫槽：中央榫槽磨痕最深，是连接两侧构件的受力节点。

- 无名手印：石背留着搬运者的手印，大小不同，没有一只手能独自举起整块石头。

修复步骤：

- 这座牌坊的形制是？（解法：四柱三间）

- 将匾额托斗归位。（解法：中）

记住后的回应：牌坊：你记住了无名者，石头才不只替显赫的人说话。

抹去旧记忆后的回应：牌坊：旧名字的回声离开了心舍。你仍可以选择把无名者的位置留在世界上。

守护前对白：牌坊：白蚀正抹平柱脚手印。施展飞檐越过灰幕，护住承重节点。

任务结语：中央构件归位，牌坊重新立稳。柱脚的手印一一显现，其中一只手指向背面的营造刻痕：那里没有名字，却有一套清楚的做法。

### 8. 无名匠

任务 ID：`archway/archway_craftsman`。场景：牌坊背面。奖励：坊·匠魂。完成修复与抉择后进入守护战。

开场对话：

1. **檐下谱**：背面的营造记录写满尺寸，署名处却空着。凿子与木屑落在石台边。

2. **牌坊·匠人回声**：若后人知道怎样修它，不知道我的名字，也不算白做。

3. **拓印师**：可我还是想替你补上。

4. **牌坊·匠人回声**：别猜。猜出来的名字会盖住真正的空白。记下你确实看见的手、工具和做法。

5. **拓印师**：用斗拱承住构件，再借飞檐点亮高处刻痕。让别人也能照着修。

6. **牌坊·匠人回声**：这就对了。传下去的不是一块永不坏的石头，是坏了以后仍有人肯修。

调查线索：

- 凿口木屑：凿口有三层深浅，显示构件曾被不同的手修过。

- 承重点：尺寸记号相互呼应，低处承重点需要斗拱稳住。

- 高处刻痕：高处刻痕反光微弱，借飞檐的灵动才能让整段记录显影。

修复步骤：

- 用斗拱承住摇晃的牌坊。（解法：斗拱）

- 用飞檐触发远端墨印。（解法：飞檐）

### 9. 登塔

任务 ID：`tower/tower_ascent`。场景：通天塔七层。奖励：塔·初代之忆。完成修复与抉择后进入守护战。

开场对话：

1. **檐下谱**：墨塔每层都收着被删去的谱页。越往上，纸越白，人的轮廓也越淡。

2. **初代拓印师·塔中回声**：我抹去战乱，抹去离别，抹去羞耻与失败。我只想让他们不再痛。

3. **拓印师**：可你也抹去了为什么相助，为什么重建，为什么等一个人回来。

4. **初代拓印师·塔中回声**：我留下了完好的屋子，为什么里面越来越空？

5. **拓印师**：因为活着的人会难过，也会改变。你替他们删掉了再次选择的来路。

6. **墨塔**：把第一道墨线接回承重点，再净化逆结晶。不要替我辩解，替后来的人打开门。

调查线索：

- 被删谱页：第一层谱页记着灾后重建，灾难被删去后，连伸手相助的缘由也消失了。

- 第七层墨线：第七层承重线断在纸白处，斗拱能稳住结构，不能替它编造过去。

- 逆结晶：逆结晶把被删去的情绪压成白蚀。用藻井净化，让记忆重新可以被阅读。

修复步骤：

- 拓印塔心第一道墨线。（沿笔画描摹，允许单笔重描）

- 用斗拱承住第七层。（解法：斗拱）

- 用藻井净化逆结晶。（解法：藻井）

记住后的回应：初代回声：请连我的错误一起记下。别让后来的人只看见一座完好的塔。

抹去旧记忆后的回应：墨塔：你又做了一次有限的取舍。承认自己无法全知，才不会把个人的谱当成整个世界。

### 10. 千层墨

任务 ID：`tower/tower_ledger`。场景：通天塔记忆长廊。奖励：塔·檐下折中。本任务不含战斗。

开场对话：

1. **檐下谱**：长廊摆着你亲手拓下的记忆，也摆着你亲手放开的空页。两者都没有消失过。

2. **拓印师**：我来时想找回自己的名字，后来却一直在替别人留下声音。

3. **廊桥的回声**：你怎样等人归来，就是你的名字。

4. **戏楼的回声**：你肯听下一句，就是你的名字。

5. **初代拓印师·塔中回声**：这支笔不该替所有人决定。你愿意把它交回去吗？

6. **拓印师**：我会留下能够证实的记忆，也留下空白。愿意接笔的人，请从自己的故事开始。

调查线索：

- 彩色拓印：记住的拓印仍有颜色，它们是这趟旅程真实携带的部分。

- 遗忘账册：遗忘页的账册没有被擦掉。承认取舍，才能看见自己记忆的边界。

- 留白之笔：桌上有三支未用的笔。世界的后续应由不止一个人写下。

修复步骤：

- 这支笔将怎样交还人间？三种回应都可以完成旅程。（任选一种回答，均可继续）

记住后的回应：檐下谱：这本谱终于有了最后一页——但没有写‘终’。

抹去旧记忆后的回应：檐下谱：你为新页放下了一段旧声。它仍在账册里，提醒后来的人：这只是你的一种选择。

任务结语：你把檐下谱放在塔门口。有人补上家门前的桥，有人画出从未登台的孩子，也有人在空白处写下疑问。屋檐不再只收留过去，它开始收留明天。
