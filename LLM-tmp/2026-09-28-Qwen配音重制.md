# Qwen 3.1 配音重制（2026-09-28）

已使用 `qwen-audio-3.1-tts-flash` 重制并接入全部 184 段配音（约 18 分 22 秒），包含对白、线索、结语、收藏回声和失败台词。沿用原音频文件名与事件索引，省略号仍为静默，不额外合成。

## 生成与声音规范

- 使用台词原文，保留问号、感叹号及停顿，不再采用旧 ChatTTS 的句号化文本。
- 每个角色固定系统声线；旁白与檐下谱保持同一声线。以自然普通话、清晰吐字、克制情感为指令，不添加气声、笑声或背景音。
- 24 kHz、单声道、16-bit PCM；移除直流偏移，仅裁去首尾近静音并保留约 100 ms 缓冲。按有声样本 RMS 做音量对齐，峰值上限 -3 dBFS，边缘 8 ms 淡入淡出。
- Godot 导入关闭 QOA 有损压缩，使用 PCM。收藏人声取消低保真失真；侵蚀只使收藏回声每点降低 0.04 dB。
- 说话时降低背景音乐与提示音；收藏播放、暂停及结束也正确压低／恢复背景音。快速调查只播放最新线索，调查结束不再自动重复积压的往事。

## 资源与复现

- 当前游戏资源：`客户端/assets/voice/`。
- 生成结果与逐条声线、原文、请求 ID、校验和：`../Art_Material/Generation/生成音频/Qwen-3.1/`。旧 ChatTTS 源素材保留为历史资料，游戏已改用新文件。
- 工具：`../AI配音台词/工具/generate_qwen_voice.py`。通过环境变量 `DASHSCOPE_API_KEY` 注入密钥；`--limit 3` 试生成，`--install` 要求全量校验成功后才替换。重复运行依据文本、声线、指令和哈希跳过已有结果。
- API 使用用户指定工作空间的语音专用路径 `/api/v1/services/audio/tts/SpeechSynthesizer`。密钥未写入脚本或记录。
- 旧游戏配音备份位于忽略的 `.review/tts/previous-voice/`。历史发行 ZIP 与参赛快照未重打包。

接口依据：[阿里云非实时语音合成](https://help.aliyun.com/en/model-studio/non-realtime-tts-user-guide)、[3.1 系统声线](https://help.aliyun.com/en/model-studio/qwen-audio-tts-voice-list)。
