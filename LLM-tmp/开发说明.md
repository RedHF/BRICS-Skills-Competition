# 檐下千秋 开发说明

2026-09-14，内容协议 v9。当前范围为五章十任务，策划依据见 `01-策划案/剧情任务功能策划案.md`。历史四任务或账号版说明不再作为开发契约。

`服务端/content/chapters.json` 是任务、剧情、墨灵、技能与数值的唯一数据源。`internal/content` 启动时验证结构；HTTP 层公开剧情和图式选项，保留知识答案与技能目标；`internal/rules` 验证描摹、步骤顺序、作用目标和战斗时间线；`internal/store` 原子持久化玩家和会话。

主流程为调查 → 解谜 → 取舍 → 战斗 → 结算。取舍立即入账，战斗失败也不撤销；回溯恢复谜题和起点侵蚀，有墨痕扣 1、无墨痕免费，重放请求不重复扣款。一个本地玩家只能推进一个未完成事件。

结算采用修复40%、白蚀清除30%、记忆保留30%，另扣非描摹错误和高侵蚀分；修复度单独保留，综合分写入 quality_score，scoring_version=2。旧结果原值保留。完整公式与八场战斗参数见策划案。

客户端 `main.gd` 编排页面与流程；`trace_canvas.gd` 采样描摹；`join_canvas.gd` 处理归位；`skill_scene.gd` 处理同场作用目标；`pattern_option.gd` 绘制选项图式；`battle_arena.gd` 绘制战斗反馈；`soundscape.gd` 播放打包音频。主导航与战斗操作栏位于滚动区外。切页暂停保留的是本次运行内的画布与战斗；重启只恢复服务端已提交的步骤，进行中战斗从准备页重开。

修改技能谜题时同步配置 answer（技艺）和 target（beam、bell、inscription）；顺序表示构件依赖，不能跳步。保持已有步骤 ID，以兼容旧存档的 accepted_steps。修改音效后可运行 `python LLM-tmp/联调脚本/generate_audio.py` 重新生成确定性 WAV。绘图与音频均为项目自有代码生成，不依赖在线服务。

## 检查

```powershell
go -C LLM-tmp/服务端 test ./...
go -C LLM-tmp/服务端 vet ./...
```

Godot 测试需全新隔离存档。`tests/integration.gd` 覆盖描摹偏移、重描、暂停、回声、战斗与失败；`tests/review_journey.gd` 覆盖十任务界面、图式、场景目标、确认按钮和操作栏可见性。启动步骤见运行说明。后者读取服务端内容作为测试答案夹具，导出时排除 tests。

不要用现有 export_presets 的旧默认路径直接覆盖发布包。本轮验证源码与独立测试服务；正式导出需在后续交付整理中指定新输出目录并同时复制 v9 服务端内容。
