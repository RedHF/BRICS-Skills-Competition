从仓库根目录运行 `go -C LLM-tmp/服务端 run ./cmd/server`，再用 Godot 导入 `客户端/project.godot`。需要本机服务正常运行；连接失败时显示重连入口，不进行离线假结算。无需互联网、账号或密码。

本轮修复零墨痕回溯死锁、三项结算、战斗数值与固定操作栏；图式辨认改为看图，技能机关改为选技艺并点击作用构件。新增侵蚀条、结算回看、已读跳过、音效和合成配乐，改善调查标签与竖幅收藏图。

开发服务默认保存到 `服务端/data/save.json`；发布客户端启动配套服务时保存到 `%APPDATA%/Godot/app_userdata/檐下千秋/save.json`。测试使用独立临时目录，不重置真实存档。
