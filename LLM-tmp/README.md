# 《檐下千秋》可运行交付

> 2026-09-12 更新：当前源码已升级为免登录剧情任务版（内容 v7），包含五章十任务、60 句开场对话、30 条调查线索、剧情回顾与三种终章回应。以下账号版说明为旧交付记录；当前规则与运行方式请见 [剧情任务功能策划案](01-策划案/剧情任务功能策划案.md)、[完整任务对话脚本](02-叙事脚本/剧情任务与对话脚本.md) 和 [剧情版运行说明](剧情版运行说明.md)。

Windows 客户端请以 `交付/檐下千秋-Windows/`（或同目录下最新剧情版发布包）为准。解压完整目录后双击 EXE；无需安装 Go 或 Godot。客户端会启动同目录的本地服务端，退出时关闭自己启动的服务端。

本次按正式策划案的演示范围完成序章与社庙三事件。后续章节的剧情草稿仍保存在内容目录，地图明确标为草稿，未把待确认结局当作完成内容。

- 竖屏界面采用 540×960 布局、底部导航和章节卡片。拓印逐字放大，显示宽容差带和未通过笔画编号，可直接重描任意一笔。服务器核验轨迹、笔顺、方向和连续性；文字答案不能替代描摹。
- 墨灵、事件、剧情和拓印线条只维护 `服务端/content/chapters.json`，客户端从服务端获取公开目录，不再保存另一份答案和文案。
- 按当前调试需求保留本地 JSON 存档。修复了完成事件在复制时丢失、会话切片共享、重复请求及抉择写入时序的问题。
- 流程为解谜 → 心舍抉择 → 战斗 → 结算。抉择立即写入账册，已拓印记忆不因战斗失败消失。

详见 [运行说明](启动客户端.md)、[内容维护](服务端/content/README.md)、[开发说明](开发说明.md) 和 [测试记录](测试复盘.md)。

回声播放打包的中文合成朗读，可暂停、继续和重听。白蚀具有血量与攻击预警，挥墨造成伤害，斗拱抵挡攻击，藻井造成伤害并净化受蚀；准备完成后才开始计时。技能说明位于战斗按钮下方、墨灵详情和心舍技艺册。

当前版本打开后直接进入地图与剧情，不注册、不登录、不输入密码，也不请求访问令牌。每台设备使用一个本地匿名档案，进度写入发布目录的 JSON 文件；删除该文件会清空进度。旧账号/第三方接入文档仅作历史记录，已不参与运行流程，详见[历史鉴权文档](服务端/鉴权与第三方接入.md)。

拓印收藏图均为随包提供的静态 PNG，运行时只读取本地资源，不调用生图接口、不实时生成成品。十张图片已使用 DashScope `qwen-image-3.0-pro` 离线生成；提示词、端点说明和失败重试记录见[生图记录](../output/imagegen/生成记录.md)。
