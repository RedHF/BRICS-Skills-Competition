# LLM-tmp · 《檐下千秋》参赛工作区

本文件夹同时保存策划/叙事/AI 留痕和可运行原型。正式提交用的成果仍按赛题要求整理到 `Task01/Final/`、`Task02/Final/`、`Task03/Final/`；`Task01/Original/` 需要保留可追溯的原始留痕。

| 目录 | 内容 |
|---|---|
| `01-策划案/` | 游戏策划案草稿及后续版本 |
| `02-叙事脚本/` | 章节叙事脚本、台词与演出文本 |
| `03-AI协作留痕/` | 留痕方案 + 各推演场景的提示词/AI 输出/逐轮记录（评分点 1.6 证据） |
| `客户端/` | Godot 4 可运行客户端：数据驱动章节、谜题、战斗、记忆抉择和结算 UI |
| `服务端/` | Go 1.22+ 服务端：权威存档、会话校验、结算和幂等持久化 |
| `联调脚本/` | PowerShell 冒烟流程，覆盖从玩家创建到重复结算 |
| `04-工具/` | 自建小工具（如 PDF 文本提取脚本） |

## 运行原型

先启动服务端（联网模式）：

```powershell
cd LLM-tmp
.\启动服务端.ps1
```

再用 Godot 4.2+ 导入 `客户端/project.godot` 并运行。客户端默认连接 `http://127.0.0.1:8090`，项目设置中的 `yanxia/server_url` 可修改地址。也可以不启动服务端，客户端会明确进入仅内存的本地演示模式。

服务端联调：

```powershell
.\联调脚本\smoke.ps1
```

服务端唯一的运行时存档位于 `服务端/data/save.json`（已加入 `.gitignore`，不作为源码交付）。客户端 `user://yanxia_identity.cfg` 只保存玩家身份指针，不保存进度；在线进度、记忆账册与星级结算均由服务端持久化和重算。
