# 剧情任务版运行说明

当前源码为内容 v9（2026-09-14），直接进入地图，无注册、登录与密码机制。

从仓库根目录启动配套服务：

```powershell
go -C LLM-tmp/服务端 run ./cmd/server
```

再用 Godot 4.5.2 打开 `客户端/project.godot` 并运行。发布版由客户端自动启动同目录的 `server/yanxia-server.exe`，需保留 `server/content/chapters.json`。

地图点击“前往任务”进入全屏对话演出；背景和台词淡入，文字逐字显现。点击窗口任意位置直接进入下一句，空格/回车也可推进；底部小型文字入口保留上一句、跳过与返回。对话结束后调查三个标记，阅读线索，再开始修复。已完成的故事在底部“剧情”中回顾。查看心舍、剧情册和设置时，当前描摹与战斗暂停，点击“返回当前事件”继续。

章节依次开放，无墨痕门票。心舍五格起步，社庙章末六格、牌坊章末七格。容量不足时须选择旧记忆替换并确认；已学技能仍可使用。终章三种回答均可完成，首次确认后保存。所有章节在零墨痕时可免费回溯失败事件；图式题看图选择，技能机关先选技能再点击构件。战斗技能栏固定可见，每场按30–60秒目标配平。剧情册保留结算快照。

发布版存档为 `%APPDATA%/Godot/app_userdata/檐下千秋/save.json`，对话阅读位置另存 `story-<玩家ID>.cfg`。旧账号字段仅作兼容数据保留，不参与认证；首次使用最近更新的本地玩家进度，之后固定该本地进度。开发服务默认使用 `服务端/data/save.json`，与发布版路径不同。测试使用系统临时目录中的隔离存档。

如旧服务占用 8090，先退出旧版窗口及服务。客户端会拒绝错误内容版本。可通过 EXE 同级 `client.cfg` 或命令行 `-- --server-url=http://127.0.0.1:8097` 指向另一个本机端口；本版本只连接本机服务。

当前 Windows x64 发行包为 [檐下千秋-v9-Windows-x64-20260914.zip](../dist/檐下千秋-v9-Windows-x64-20260914.zip)，完整解压后双击“檐下千秋.exe”，无需安装 Godot 或 Go。包内附带配套服务、最新策划与叙事文档及 SHA256 校验值；旧发布包和正式提交目录保持原样。音频设备不可用时可用 `--audio-driver Dummy` 做无声界面测试，但这不构成听感验收。

## 拓印图片生成

使用 `output/imagegen/generate-rubbings.ps1`，从当前进程的 `IMAGE_API_KEY` 环境变量读取密钥。模型列表中对应 `image2.5` 的可用命名为 `gpt-image-2.5`，脚本默认使用该名称，不使用 Python。

```powershell
./output/imagegen/generate-rubbings.ps1 -Force
```

脚本按十个独立提示词生成 PNG，并复制到客户端 `assets/rubbings/`。当前 DashScope 版本使用 `generate-dashscope-rubbings.ps1` 和 `qwen-image-3.0-pro`；生成后重新导入并导出 Godot。游戏本身完全不调用生图接口；缺图时显示“拓印图待装裱”。完整测试和模型切换记录见 `output/imagegen/生成记录.md`。

## 验证

```powershell
go -C LLM-tmp/服务端 test ./...
go -C LLM-tmp/服务端 vet ./...
```

客户端集成测试需独立、全新的本地服务与存档，监听 8097；使用隔离 APPDATA 后运行：

```powershell
godot --headless --path LLM-tmp/客户端 --script res://tests/integration.gd -- --server-url=http://127.0.0.1:8097
```

十任务界面回归使用 `res://tests/review_journey.gd`，另开全新存档服务并用 `-- --server-url=http://127.0.0.1:8098` 指定端口。可设置 `YANXIA_REVIEW_SHOTS` 指向截图目录；图形模式会输出画面，headless 只检查流程。

新对话暂未逐句配音；墨灵详情仍可播放原有摘要回声。后续章节目前以静态拓印图作为叙事背景，非新增完整场景原画。

失败会先进入九句〈飞鸟山〉演出，首句随失败原因变化；第九句结束后显示回溯。读到一半退出后可续读，同一次失败读完后不会强制重复，新一次失败重新播放。戏楼两个任务首次结算会在结语下显示通关呓语。新增场景尚用既有残迹背景占位，台词暂无逐句配音。
