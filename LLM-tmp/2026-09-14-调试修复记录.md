## 2. 数值与兼容口径

修复度是已得谜题分 / 谜题总分；清除度是已清波数 / 总波数，无战斗任务按 100 参与计分，界面标识无战斗。记忆保留度是结算时持有数 / 历史获得的不同墨灵数，历史获得按账册去重，分母为零时取零。综合分为三项按 40%、30%、30% 加权后扣除错误与高侵蚀分，限制在 0–100；85 分起三星、60 分起二星，其他一星，墨痕奖励等于星级。每次非描摹错误扣 5 分，最多 20；结算侵蚀 ≥70 另扣 15。

完整修复、全部清除、无扣分时，保留 7/10 为 91 分三星，保留 1/10 为 73 分二星。有限心舍容量下的正常取舍仍可三星。旧存档已完成结果保持原值，客户端标注旧版口径；未完成会话采用当前内容数值，原有步骤 ID 与已确认取舍不变。内容协议同时升级，v8 客户端不能混用旧服务端。

这些是自动驱动的游戏内时间，不是实测真人通关耗时。战斗模型另覆盖 0.5 秒及 0.75 秒输入间隔、起始侵蚀 50，均在目标范围获胜。阅读速度、谜题难度与整部作品总时长仍需真人试玩评估。

## 4. 复现与维护

从仓库根目录运行（Go 1.22+，Godot 4.5.2）：

```powershell
go -C LLM-tmp/服务端 test ./...
go -C LLM-tmp/服务端 vet ./...

# 终端 A：为每次完整测试准备独立目录和全新存档；不要指向日常 save.json。
$reviewData = Join-Path $env:TEMP ('yanxia-qa-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $reviewData
go -C LLM-tmp/服务端 run ./cmd/server -addr 127.0.0.1:8098 -data (Join-Path $reviewData 'save.json')

# 终端 B：隔离客户端设置；把 godot 换为本机 Godot 可执行文件。
$env:APPDATA = Join-Path $env:TEMP ('yanxia-client-qa-' + [guid]::NewGuid().ToString('N'))
$env:YANXIA_REVIEW_SHOTS = Join-Path $env:APPDATA 'shots'
New-Item -ItemType Directory -Path $env:YANXIA_REVIEW_SHOTS -Force
godot --path LLM-tmp/客户端 --audio-driver Dummy --script res://tests/review_journey.gd -- --server-url=http://127.0.0.1:8098
```

原 `integration.gd`、`smoke.ps1` 应各使用另一个全新隔离服务端存档；不要将多个测试同时指向同一存档。视觉夹具在完整旅程后运行，使用同一个 QA 服务端。发布时应重新构建匹配 v8 的客户端和服务端，本轮没有覆盖旧包。

最新策划入口：[剧情任务功能策划案](01-策划案/剧情任务功能策划案.md)；剧情入口：[剧情任务与对话脚本](02-叙事脚本/剧情任务与对话脚本.md)。版本关系见 [文档版本索引](文档版本索引.md)，新增音频来源见 [音频素材说明](客户端/assets/audio/README.md)。
