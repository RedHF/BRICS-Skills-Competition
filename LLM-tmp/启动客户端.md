# 客户端运行说明

1. 完整解压最新 Windows 发布包（优先使用 `交付/檐下千秋-Windows/`）。
2. 双击目录中的 `檐下千秋.exe`。保留同级 `server` 文件夹及其 `content/chapters.json`。
3. 开屏后直接进入地图，无登录、注册或密码步骤；本地服务自动创建/恢复匿名存档。
4. 在古建地图选择序章，随后依次完成五章十任务。进度保存在本机，退出后再次启动会继续上次任务。

程序为 Godot Windows x64 导出的可执行文件，资源已嵌入 EXE。附带 Go 服务端 EXE，不依赖编辑器、Go 工具链或启动脚本。

窗口默认为 450×800，按 540×960 竖屏布局缩放，底部导航固定。

拓印逐字放大：绿点起笔、橙点收笔；金色带的半径为当前字画布高度 14%（默认窗口约 35 像素），允许短暂手抖与小幅回描。提交后未通过的笔画与编号标红并带 ×，点击编号只重描这一笔，其他笔画保留；描摹练习不增加侵蚀。

白蚀战斗先阅读说明，再点击“开始守护”。点击挥墨攻击；斗拱抵挡后续两次攻击；藻井造成伤害并消除一次受蚀；技能冷却显示在按钮上。白蚀每三秒攻击，攻击前变红；消灭各波敌人并施展本关要求的技能可获胜。超时或受蚀达到上限失败。战果由服务端按操作时间、伤害与冷却计算。

心舍的墨灵详情可“聆听墨灵回声”，播放对应记住文案的中文合成朗读，支持暂停、继续、重听，显示播放进度。技能使用说明也在心舍技艺册及每道墨灵详情中。

心舍抹除需要再次确认，抹除后的墨灵详情变灰、对应回声不再播放，账册保留来源与抉择事件。已学技艺保留，避免因遗忘锁死后续解谜。此处采用策划案所述的叙事性弱化方案，未增加技能数值惩罚。

存档位于 `%APPDATA%/Godot/app_userdata/檐下千秋/save.json`；账号与密码哈希也保存在该 JSON，服务端日志为 `server.log`。旧匿名身份文件已清除。测试使用隔离目录，不修改正式玩家存档。调试修改 JSON 前先退出对应游戏和服务端，避免被运行中的内存状态覆盖。

默认服务地址为 `http://127.0.0.1:8090`。若旧测试窗口或旧服务占用该端口，先退出旧版再运行新版；客户端会明确报告内容版本不匹配，不会切换成模拟离线存档。需要连接独立服务时，在 EXE 同级添加 `client.cfg`：

```ini
[server]
url="http://127.0.0.1:8090"
```

源码运行：使用 Godot 4.5.2 打开 `客户端/project.godot`，先启动服务端。发布版已附配套可执行程序。

当前版本只连接本机服务，不依赖远程账号或第三方登录。若需清空进度，关闭游戏后删除本地 `save.json`；旧账号版字段仅作兼容保留，不参与认证。
