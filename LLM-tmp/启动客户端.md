# 启动客户端

当前版本为内容 v10。仓库不再保留已打包的 Windows 发行包（2026-09-15 整理时全部删除）；需要时用 Godot 4.5.2 自行导出。新增配音、图片、首领和 1–5 键位见[更新说明](2026-09-14-素材配音与首领更新.md)。

源码运行：在仓库根目录启动 `go -C LLM-tmp/服务端 run ./cmd/server`，再用 Godot 4.5.2 打开 `客户端/project.godot` 并运行。客户端无需登录，连接本机服务。不要将旧服务端与当前客户端混用。存档、端口覆盖、重连和隔离测试方式见[剧情版运行说明](剧情版运行说明.md)。
