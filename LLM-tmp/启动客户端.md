# 客户端运行说明

1. 完整解压 `交付/檐下千秋-Windows.zip`。
2. 双击 `檐下千秋-正式版/檐下千秋.exe`。保留同级 `server` 文件夹及其 `content/chapters.json`。
3. 在古建地图选择序章，随后依次完成社庙三个事件。

程序为 Godot Windows x64 导出的可执行文件，资源已嵌入 EXE。附带 Go 服务端 EXE，不依赖编辑器、Go 工具链或启动脚本。

拓印时从绿点沿宽金色墨带描到橙点，松开完成一笔。允许偏离中央细线；可撤回上一笔或重描本步。提交失败仍保留已画内容。原型画布的容差半径约 26 像素，窗口缩放时与画布等比例变化。

心舍抹除需要再次确认，抹除后的墨灵详情变灰、对应回声不再播放，账册保留来源与抉择事件。已学技艺保留，避免因遗忘锁死后续解谜。此处采用策划案所述的叙事性弱化方案，未增加技能数值惩罚。

存档位于 `%APPDATA%/Godot/app_userdata/檐下千秋/save.json`；玩家身份位于同目录 `yanxia_identity.cfg`，服务端日志为 `server.log`。测试使用隔离目录，不修改正式玩家存档。调试修改 JSON 前先退出对应游戏和服务端，避免被运行中的内存状态覆盖。

默认服务地址为 `http://127.0.0.1:8090`。若旧测试窗口或旧服务占用该端口，先退出旧版再运行新版；客户端会明确报告内容版本不匹配，不会切换成模拟离线存档。需要连接独立服务时，在 EXE 同级添加 `client.cfg`：

```ini
[server]
url="http://127.0.0.1:8090"
```

源码运行：使用 Godot 4.5.2 打开 `客户端/project.godot`，先启动服务端。发布版已附配套可执行程序。
