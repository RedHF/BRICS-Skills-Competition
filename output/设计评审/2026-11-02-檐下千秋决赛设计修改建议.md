# 《檐下千秋》决赛设计修改建议

评审日期：2026 年 11 月 2 日。本文是设计评审与后续迭代建议，不代表改动已经实现，也不替代赛事规则。

## 1. 评审依据与结论

本次阅读了正式提交的八页游戏策划案、较完整的策划 Markdown、章节叙事草稿及当前十任务剧情配置，核对了正式 AI 协作记录中的制作过程，并查看了 9 月 30 日 v19 的欢迎、关卡、对白、调查、描摹、构件、机关、战斗、收藏和取舍记录截图，以及十一张环境背景和十张记忆收藏图。决赛依据为用户提供的八页《决赛路演答辩评审规则》。旧稿和历史评估只用于理解演变，不将已经补齐的背景、角色、动作、字体、配音再列为“完全缺失”。

本次未启动游戏进行新一轮完整真人试玩；关于操作节奏、理解难度和情绪效果的判断属于基于规则与画面的设计判断，需要试玩验证。

**核心结论：项目已经有完整的内容骨架，最需要补强的是主题、玩家行为和视听后果之间的联系。** “古建记忆”“有限心舍”“白蚀”具备共同的表达方向，但当前较多内容仍通过说明文字传达，操作主要是找标记、按提示描画、拖入指定位置和按冷却攻击。美术已有一定数量，缺口集中在统一风格、交互对象、状态变化和演出衔接。

建议把作品中心明确为：**通过修复与记忆取舍，让古建重新与人发生关系。** 重点体验是听懂一处痕迹、做出一次修复、承担一次选择、看见它留下的变化。

## 2. 最应该保留的设计

1. **建筑作为叙事主体。** 桥、庙、戏楼、牌坊分别保存等待、接纳、传艺和劳动，具有共同主题，也有情感差别。
2. **有限心舍。** 个人无法承载全部文明，可以自然引出“传承为何不能只靠一个英雄”的问题。
3. **普通人的微小痕迹。** 半碗饭、孩子手掌磨出的桥栏、各家捐木记号、无名手印，比抽象的王朝设定更容易形成情感。
4. **承认未知与允许续写。** 不替匠人编造姓名、不把修复等同于抹平旧痕、允许后来人接着书写，这些立场值得进入实际操作。
5. **描摹允许练习。** 单笔重描且不累积侵蚀，符合轻解谜受众；应让其他试探操作也得到相近的宽容。

建议减少开场的专有名词。玩家先经历“桥在失去归家的脚步声”，再认识墨灵、心舍和白蚀。理解感受之后，术语才有意义。

## 3. 玩法的关键问题与修改方向

### 3.1 最独特的取舍机制出现太晚

当前规则是初始五格，第四任务后扩为六格，第八任务后扩为七格，十道记忆各占一格。按一路收录、不主动遗忘推算，前六道记忆都能装下，第一次容量不足发生在第七任务“四柱三间”。这意味着玩家可能已经完成大半旅程，才第一次体验宣传中的核心矛盾。

建议在社庙章末或全程前 20%—30% 安排第一次有充分铺垫的取舍，再在戏楼和终章逐步加深。可以调整容量曲线，或安排一次具有明确情境的提前取舍；不要仅为挤满背包而突然把某张卡改成占两格。

第一次取舍应先让玩家与两段记忆都建立关系，再提出新需求。演示可从真实的取舍前存档进入，避免为等背包满而现场走七个任务；应清楚说明这是章节片段。

### 3.2 记忆选择需要具体后果，不能只停留在收藏状态

保留已学技艺，是避免玩家因情感选择而失去通关能力的合理安排。问题在于，当技艺全部保留，而变化主要发生在收藏图与回声时，取舍容易被理解为整理卡片。

建议保留基础技艺，把情感后果做具体：

| 记忆 | 保留时的可感知反馈 | 放下之后的可感知反馈 |
| --- | --- | --- |
| 檐·平安 | 桥上偶尔传来归人脚步，灯影回应一次 | 同一处只有雨声与空灯影 |
| 社·宁安 | 半碗饭旁出现另一只碗的淡淡回影 | 物件仍在，回应客人的那句声音不再随身响起 |
| 社·回春 | 鼓点带出孩子不齐整的跟拍 | 鼓可以修好，孩子的节拍不再被主角唤回 |
| 坊·匠魂 | 记忆谱能重现做法与手的动作 | 主角仍会修复，却无法完整重听那次传授 |

这些都是拟议表现，当前并未验证存在。先完成一个可见、可听的实例，再扩展。

选择前允许试听、并排看物件和后果；选择时让玩家完成简短的擦墨或合页动作；选择后留出几秒安静。正式确认仍应明确，不把剧情取舍设计成容易误触的操作。

### 3.3 “取舍无标准答案”与“保留率参与评分”存在冲突

正式规则把当前持有记忆数除以历史获得数，作为占比 30% 的评分项。虽然 7/10 仍能达到三星，保留数量依旧影响分数，玩家仍可能读出“留得越多越好”。

建议从星级中移除记忆保留率。星级如需保留，只评价修复完成、关键线索理解或守护目标；记忆取舍用一页个人旅途结果呈现，不列价值排名。结算可以展示“修复了什么、带走了什么、留下了哪处空白”，让结果体现选择，而不是给感情计分。

### 3.4 必须解释“为什么不把所有记忆写进普通册子”

当前个人容量限制与抢救文化的目标之间，需要一个清楚的世界规则。否则玩家会问：既然能够记录，为什么必须抹除？主角的行为与初代拓印师的抹忆又如何区分？

建议明确两层：**档案可以留下已经证实的痕迹；心舍只能承载少量能被亲身唤起的鲜活记忆。** 放下之后可以知道“这里曾有人等待”，却无法再完整听见那个人的声音。普通档案与鲜活共鸣具有不同价值，不能用无限回放悄悄抵消设定中的代价。

决赛前可先澄清文案和一种后果。后续再发展“托付”：把做法教给愿意继续修的人、把社鼓交还节庆、把戏声交给后来者。托付需要先完成对应行动，并放弃随身唤回某段独特声音的能力。这样，有限容量推动传承，而不是把删除文化当成终点。

### 3.5 谜题需要玩家观察和判断

现有谜题往往把目标和顺序直接写出，玩家主要照着执行。比如按提示放入左、中、右，或在已标明名称的图式中选择。这样的引导适合教学，后续应逐步撤去。

建议每章设置一种主要的思考方式：

| 篇章 | 主要玩法 | 玩家需要判断什么 | 情感结果 |
| --- | --- | --- | --- |
| 廊桥 | 观察磨损、局部拓显 | 哪些痕迹来自反复等待的人 | 字背后有人，而不只是一个答案 |
| 社庙 | 比对构件、确定装配顺序 | 余料如何凭榫口、记号彼此接合 | 一屋由众人合力撑起 |
| 戏楼 | 听节拍、接续回应 | 不完整的旧腔如何接上新声 | 传承可以包含变化 |
| 牌坊 | 比对正背面、整理证据 | 什么有依据，什么仍应留白 | 没有姓名也能看见劳动 |
| 墨塔 | 重组此前记忆与记录 | 个人承载与交还他人的边界 | 用行动收束主题 |

具体改法：构件提供少量外形接近、榫口不同的候选，让玩家旋转和比较；正确装配后显示离散的梁架稳定状态即可，无须重做物理系统。牌坊让玩家先观察空间结构再选图，选项下不直接附上完整答案。描摹加入局部显影和旧痕辨认，减少连续多个字的机械重复。

不要把所有章节都扩成新小游戏。决赛前只把一类谜题从“按说明操作”改到“观察后能解释为什么这样做”。

### 3.6 守护战与“遗忘”的主题联系偏弱

八场守护战以伤害、冷却、波数和限时为主要变化，三项技艺更接近常见的防御、远程和净化。仅按技能一次来满足通关条件，容易变成检查清单。

建议逐步把目标改成“守住正在消失的东西”。例如噤声客吞去戏台上的回声，玩家需要承住梁架、引响远处机关、显出被遮蔽的纹样，最终让一句唱腔得到回应。技艺由场景需求决定，战斗中的操作也就能解释其文化来源。

决赛前优先做一场首领的清楚阶段与环境变化，压缩重复攻击。后续才考虑把八场缩为两至三次有独立意义的守护事件。完整战斗系统重做不应抢走代表关卡的打磨时间。

### 3.7 统一任务模板削弱节奏

每关六句开场、三个调查点、修复、收录、守护、结算，结构容易被玩家预判。步骤完整不等于体验需要同样长。

建议有的关卡先发生异常再调查，有的只围绕一件物品，有的修复完成便安静结束。让玩家直接走进相邻空间，减少每个短任务都返回选择页和结算页。十任务可以保留，呈现节奏应有疏密。

### 3.8 失败演出与终章还需更准确地回应行为

飞鸟山九句不可跳过，且后段对主角进行较强的道德质问。若玩家只是拖错构件或战斗超时，就被指向“自私的修复者”，行为与评价并不对应。重复看长演出本身也会形成惩罚。

建议首次失败保留完整气氛，重复失败允许缩短或跳过；操作错误得到具体反馈，修复伦理的质问放在玩家确实作出过相关选择之后。彩蛋若保留，可移到可选回声，避免打断主要叙事语气。

终章三种回应都积极、且可以相互兼容，不必勉强包装成彼此排斥的价值道路。可以让玩家决定最后一页、最后一次托付的侧重点；前面的选择决定蒙太奇里出现的物件、声音与空白。即便只有三张静态结局图，也应让它们回应玩家具体带过、放下过的记忆。

## 4. 美术的主要问题：需要建立共同的视觉语言

### 4.1 当前可见的断裂

1. **角色比例不一致。** 封面是偏写实的成年人物，实机角色头身比较小、偏 Q 版，面对同样偏写实的建筑容易产生贴图感。
2. **场景与谜题脱节。** 调查是整张环境图；进入修复后，道具摆在大片纸面上，玩家很难感觉自己仍在那座建筑里修复。
3. **界面挤占交互区域。** 1280×720 截图中，顶部与背景留白较多，实际调查、战斗窗口明显偏小，右侧较长文字与小字号还削弱了重点。
4. **纹理强于信息。** 大量墨刷按钮、黄纸、山水背景同时出现，次要装饰与主要操作争抢注意；浅字在灰墨底上也不够醒目。
5. **同一建筑缺少连续性。** 牌坊整体图偏石构，修缮近景偏木构，收藏图的轮廓又有差异。对玩家而言，正背面、修复前后、收藏拓片应能认出同一处建筑。
6. **状态资产弱于背景数量。** 有场景不等于能呈现修复。应明确破损在哪里、什么被修好、遗忘之后哪一处回应消失。

### 4.2 推荐美术方向

建议以现有记忆收藏图中较统一的墨色、纸感和少量淡彩为锚点，形成“纸上古建，墨中人间”的整体表达。环境降低摄影式质感和零散细节；主角采用成年比例的简化墨色形体，保留毛笔、谱册和少量朱色标志。无需追求大量精细角色动画。

这是推荐方向，不要求立即重画所有环境。决赛前先选一处场景、一种修复画面、一张记忆页作为基准，把其他可见元素往同一方向收拢。

建议约定以下视觉语义：

| 状态 | 画面语言 | 声音语言 |
| --- | --- | --- |
| 留白 | 边界完整、纸面干净、有呼吸空间 | 安静但保留环境 |
| 白蚀 | 墨线被截断、局部结构与纹样缺失 | 句子或节拍被截断 |
| 修复 | 墨线重新连接，旧裂痕仍可辨认 | 环境里出现明确回应 |
| 鲜活记忆 | 少量暖色聚焦于碗、灯、鼓槌或手印 | 人声、脚步或鼓点回到具体位置 |
| 放下记忆 | 对应细节停止回应，其他空间仍然存在 | 一条具体声部退出 |

“留白”和“白蚀”不能都只是白色。“修复”也不宜只等于整体变亮或变成全新建筑。

### 4.3 界面修改建议

调查与守护阶段，让环境占主导；以约 70%—80% 的屏幕宽度作为构图起点，具体比例需实际排版验证。主目标压到一句，操作提示就近出现，历史线索按需展开。顶栏只留当前阶段必需状态。

描摹与构件归位可以使用纸面，但应通过镜头靠近、物件提取或纸页展开，让玩家看懂它与场景的关系。归位成功后回到同一位置，看见梁落稳、檐下少一滴雨，避免一直留在独立道具页。

文字使用稳定、清楚的底板；书法字只用于题名和少量强调。主要操作、次要导航、已完成和不可用应具有容易辨认的差别，不能只靠墨刷深浅区分。战斗提示靠近行动位置，长说明移到准备阶段。

## 5. 美术补充清单与优先级

| 优先级 | 交付项 | 用途与验收重点 |
| --- | --- | --- |
| P0 | 一张风格基准板 | 同页放主角、环境局部、拓片、物件、按钮和色板，统一比例、线条与明暗 |
| P0 | 代表场景的受蚀／修复／选择后状态 | 同构图，关键物件位置一致，一眼能找到变化；优先局部图层而非重生成三张不一致的图 |
| P0 | 代表谜题的局部建筑与构件 | 构件能认出属于场景，榫口与归位关系明确，不再像无来源的纸上道具 |
| P0 | 一张完整记忆抉择页 | 用两件物品、两句回声和后果帮助选择，空白和擦除有明确语义 |
| P0 | 代表关卡中的主角比例与接地处理 | 与封面身份一致，脚底位置、透视、影子、动作尺度协调 |
| P0 | 统一的主要按钮、提示与对白底板 | 缩到演示画面大小仍可读，正文不压在复杂纹理上 |
| P1 | 噤声客独立轮廓与阶段表现 | 能与普通白蚀区分，吞声和回响的变化清楚 |
| P1 | 三张同构图终章图或三个局部变化 | 分别突出手艺、记录和后来者，并回收玩家实际记忆 |
| P1 | 五章路线图与建筑一致性表 | 同一古建跨场景保持材质、轮廓、关键构件位置的连续性 |
| P1 | 关键交互短演出 | 拓显、构件扣合、回声出现、记忆放下各一个；手感与节奏优先于帧数 |
| P2 | 其余关卡逐步补齐状态与演出 | 代表关卡验证有效后，再复用规范铺开 |

现有十一张独立背景、十张收藏图、十八张动作帧、184 段配音已经构成基础。下一批制作应围绕玩家会看见的变化，不以新增素材数量为目标。

## 6. 建议打磨的代表片段：社庙“檐下不拒客”

社庙有余料修梁、半碗饭、借檐避雨等具体物件，容易把古建结构和人的关系同时讲清。可把相邻事件在展示中组织成连续的一段，而非现场跳多个不相关界面。

下列是约两分钟的展示设计目标，不是现有功能或真人实测时长：

| 展示段落 | 玩家动作与现场画面 | 需要证明什么 |
| --- | --- | --- |
| 进入 | 雨水滴在空碗边，梁架不稳，回声断在半句话 | 建筑正在失去人的回应 |
| 观察 | 对比两段余料上的接合位置和捐木记号 | 线索来自物件，玩家可以判断 |
| 修复 | 先承住主梁，再选构件与方向归位 | 理解结构之后采取行动 |
| 显影 | 梁落稳，漏雨减弱，碗边出现一段旧日回声 | 操作产生环境与叙事结果 |
| 取舍 | 从有充分前情的两段记忆中选择带走哪一段 | 有限承载带来具体情感选择 |
| 回应 | 某条声部留下，另一处安静；屋檐仍能遮雨 | 选择有后果，传承仍能继续 |

若新片段制作量过大，可用现有关卡完成较小版本：保留当前社庙背景，补一个构件局部、一次修复状态和一处回声变化。先做到动作、结果、主题三者能被同时看见。

## 7. 决赛前的工作取舍

### 第一批：最值得立即处理

1. 写清鲜活记忆与记录的区别，移除记忆保留率的价值评分。
2. 将第一次有意义的取舍提前，并使后果具体可见。
3. 选一处代表关卡，把观察、修复、显影、取舍串成完整体验。
4. 统一该片段角色、物件、场景和 UI 的视觉基准，放大主要画面。
5. 用一组同构图前后变化和一段短演出证明修改价值。
6. 缩短重复失败演出，修正操作失败与道德评价的错位。

### 第二批：有余量再推进

噤声客的独立阶段；终章对玩家记忆的个性化回收；其他章节的观察谜题和环境状态。完整战斗重构、全场景重画、额外养成或大量新关卡属于后续版本。

以上优先级依据设计影响与现有材料判断，未做人员工时估算。正式规则写提交“选拔赛阶段作品的三个 final 文件夹中的内容物”，未在这份材料里明确新迭代替换范围；本报告不把设计建议视为赛事对版本变更的授权。

## 8. 让五分钟汇报有一条清楚的证据链

规则限定作品呈现与汇报不超过五分钟、含提问总计不超过八分钟。评分为策划 33、核心制作 24、成果呈现 33、答辩 10；“作品完成度与核心呈现”14 分是最高单项，风格统一与主题视觉表达为 6 分，AI 制作工作流与过程记录为 8 分。

建议按以下目标分配五分钟，并在排练后调整：

| 时间 | 内容 |
| --- | --- |
| 0:00—0:20 | 一句话提出文化问题，让观众看见一处正在失去回应的建筑 |
| 0:20—1:00 | 一张图解释修复循环和有限心舍，少讲专有名词 |
| 1:00—3:00 | 代表片段实机：一次观察、一次操作、一次取舍、一个结果 |
| 3:00—3:45 | 美术与交互迭代前后对照，说明为何这样改 |
| 3:45—4:30 | 一个真实 AI 工作流案例：约束、候选、人工判断、修订、实机采用 |
| 4:30—5:00 | 呈现整体完成范围与终章回收，留出自然结束时间 |

AI 部分应从已有记录中挑一个真实案例，如拒绝比例不合的角色、修订场景构图以容纳调查物件、解决风格混用；展示真实候选和采用理由。模型名单、调用次数和图片总量不能独立证明设计质量，也不能事后编造人工决策。

当前正式策划案封面仍含学校名称和队伍 ID，新规则写明所有材料只可出现组别信息。应准备符合新规则的匿名提交材料，处理封面、正文自述、文件名、备注与元信息中的可识别信息。这里是已经核对到的实际材料冲突。

## 9. 用少量真人试玩检验是否改对

邀请约五位没看过策划案、接近目标受众的人体验代表片段。先不讲世界观，记录以下事实，不用单纯的“好不好玩”代替：

- 第一个操作是否能从画面和一句提示中理解。
- 是否能解释构件为什么放在那里，而不是复述系统给的顺序。
- 选择前能否说出自己在乎的两段记忆。
- 选择后能否指出具体少了哪个声音或细节。
- 是否能用自己的话解释修好建筑与文化传承之间的关系。
- 是否在哪处停下来读说明、误点、反复失败或开始机械点击。

若玩家记住的只有“描字”和“打怪”，应继续调整代表片段；若能记住“有人把半碗饭分给陌生人，我修好的是能让人避雨的屋檐”，主题才开始成为体验。
