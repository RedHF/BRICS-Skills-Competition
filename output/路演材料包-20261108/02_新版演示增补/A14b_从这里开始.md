# A14：描摹、回声页与守护操作修订

日期：2026-11-08。根据本轮四张试玩截图修改。当前候选以 `dist/回响版-当前预览.md` 为准，完整解压并退出旧程序后运行。

- 描摹：移除右栏十八个编号按钮和重复缩略图，使用上一笔/下一笔；保留当前笔、重描、核对。右侧操作不依赖滚动；上方笔画提示留出完整空间。
- 回声选择：有空位时将收录和只留记录按钮放在右栏底部。
- 技能操作：挥墨、飞檐、闪身使用图标、圆形遮罩和环形冷却；斗拱自动护盾、藻井自动净化，不占底部操作按钮，未学会时不触发。键盘主动操作仍为 1、4、5。
- 演出：攻击增加金墨放射、双环扩散，飞檐增加多道残影。复用现有水墨贴图，不新增整套生图素材。
- 守护规则：回响版每场从零计算受蚀，90 秒内清除目标；达到本场受蚀上限或超时才失败。取消“所有技能必须手动按一次”的清单判定。失败进入可免费重试的守护页，保留修复与取舍，不包装成剧情 BE。此轮仍为波次守护，未声称已经完成后续三阶段情境首领。
- 戏楼辨认：用带参照的衣袖轮廓比较替换难辨认的旧人物图；提示与选项统一为形状比较，不要求猜行当名称。它是清楚的游戏示意，不作为真实戏服规范教学。
- 回声详情：分离旧播放器的更新状态，避免访问已释放的播放器控件；回到当前选择/事件时恢复原页面和进度。
- 保存：对 Windows 短暂文件占用导致的原子替换失败增加有界重试；不通过删除原存档规避错误。

检查包括服务端测试、受击后仍可获胜的规则例子、十任务流程、描摹按钮边界和戏楼详情返回。自动确定输入不能证明初见谜题理解或战斗手感；新特效强度、图标辨识和声音仍需用户再体验。失败的检查记录保留，不改写为通过。

重复生成的验证截图不作为长期文件堆积；本目录仅保留本轮最终版本的少量精选画面。A11 路演材料依旧是历史版本。
