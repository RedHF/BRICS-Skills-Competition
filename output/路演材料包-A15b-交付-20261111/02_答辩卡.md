# 答辩卡

答辩备用为 PPT 第 8–10 页；只在评委提问时切换。回答要区分已实现、自动验证、真人体验和后续计划。

| 可能问题 | 建议回答 |
| --- | --- |
| 为什么不按稀有度或战力挑选回声？ | 事实和技艺另行保留；心舍选择的是独特回应。用数值替玩家决定情感取舍，会削弱本作的主题。 |
| 归档会删掉文化事实吗？ | 不会。发现记录、实体物件、修复用途和学会的手艺保留；退出的是那次独特回应。第 9 页有确认画面。 |
| 梁口、三结红绳是否史实？ | 梁口是游戏化简化，三结红绳是本作虚构的数拍线索；没有把它们作为特定历史仪式或现实修缮方法。 |
| AI 究竟参与了什么？ | 协助细化方案、生成参考资产、补齐角色与近景素材、实施和检查；采用前后仍看实机效果。误标和模糊案例有修正记录。不要虚构工具内部模型或团队贡献。 |
| 为什么只重点重制社庙？ | 先把代表章节的观察、修复、取舍和后果做完整；其余章节保留原玩法。全章同深度重制尚未完成，不能列为当前成果。 |
| 自动检查能证明玩家喜欢吗？ | 不能。它证明覆盖到的规则、状态、存档和导出程序能运行；初见理解、情绪分量与操作舒适度仍需真人观察。 |
| 视频是否连续通关或真人操作？ | 不是。120 秒视频由同版导出 EXE 的两个独立起点录制，采用自动真实 UI 输入，并在画面中标识。十任务完整流程另有自动验证。 |
| 与原选拔赛 Final 是什么关系？ | 原三个 Final 保留历史内容。回响版是独立增补展示；正式提交文件范围按组委会最终书面口径核对，不以新材料直接覆盖原件。 |

现场分工以实际参赛团队为准。材料没有预填无法核实的成员姓名、制作贡献或真人试玩数据。
