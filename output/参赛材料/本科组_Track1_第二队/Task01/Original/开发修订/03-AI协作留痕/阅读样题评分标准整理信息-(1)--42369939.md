1. 封面页：**作品名称 / 队伍 ID / 日期**
2. 标题：**黑体三号加粗**
3. 正文：**宋体小四，1.5 倍行距**
4. **关键词蓝色高亮 + 脚注解释**
5. 页边距：标准 **2.54 cm**
6. 字数不限，但必须完整阐述上述内容
