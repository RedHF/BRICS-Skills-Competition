## 一、游戏概述与核心概念【评分点 1.1，4 分】

### 1.1 游戏名称与核心概念

- **游戏名称**：《檐下千秋》
- **核心概念**：扮演王朝最后的拓印师，以「拓印古建记忆」为战斗与抉择的核心，在「识海只能承载数道记忆」的伦理困境中对抗白蚀、拯救墨痕王朝。

### 1.2 游戏类型与定位

- **类型**：2.5D 解密冒险 + 轻战斗（重解密与叙事；拓印技能=解密工具+战斗辅助；战斗单场 30–60 秒，不打断叙事节奏）
- **平台倾向**：PC（演示）/ 可适配移动端虚拟摇杆

### 1.3 目标受众

偏好国风叙事、策略解谜与轻度卡牌玩法的玩家（建议定位 16–35 岁）。

### 1.4 视觉风格

国风水墨基调（与「墨痕/墨灵」世界观契合）；参考官方**波克 IP「灵画师」**素材统一角色与场景风格（素材仅限参赛使用，使用记录存入 `Task02/Original`）。
> 灵画师素材建议映射（【待确认】）：角色 3D 参考 ×3 → 拓印师主角立绘 / 匠魂拟人形象 / 关键事件角色；横屏尺寸参考 → 主界面与调查场景构图基准。

### 1.5 主题切入点与文化表达

**主题维度：建筑文化的空间叙事**（赛题维度二）。取材中国传统建筑承载「记忆」的文化内涵：**风雨廊桥、社庙、戏楼、牌坊、斗拱、飞檐、藻井、通天塔**。
设计理念：传统元素「保留 + 现代化转译」——保留榫卯、墨线拓印、藻井纹样等建筑语汇，转译为游戏内的谜题机制与技能系统（见第四、五节）。

### 1.6 特色亮点（创新点）

1. **解密驱动叙事**：以古建构件的「拓印/修复谜题」推进剧情（榫卯归位、墨线拓印、文化知识谜题）。
2. **背包即「心舍」**：容量初始 5 道、上限 7 道墨灵；拓印新记忆必须亲手抹去一道旧记忆，抹除伴随视听代价（画面褪色、音效消失）。
3. **无传统 NPC**：事件与剧情由「古建呓语」发布，营造孤寂苍凉的沉浸感。
4. **轻战斗**：拓印技能快速对抗白蚀（每场 30–60 秒），不打断叙事。
5. **主题升维**：从「对抗邪恶」升华为「记忆伦理」抉择——记住什么、遗忘什么由玩家决定。

### 1.7 一句话宣传语

**「檐下藏千秋，墨中定存亡」**

## 二、核心玩法与机制设计【评分点 1.2，5 分】

### 2.1 核心循环

> 探索古建 → 聆听「呓语」接取事件 → 解密（拓印/构件修复谜题）→ 获得墨灵符诏 → 心舍容量抉择 → 轻量战斗对抗白蚀 → 修复古建推进旅程

**玩家每一步**：从风雨廊桥醒来 → 游历社庙/戏楼/牌坊等古建 → 调查场景、聆听呓语 → 解谜（拼合斗拱、拓印墨线、识别构件）获得墨灵符诏 → 为腾出识海空间不得不抹除旧记忆 → 以技能轻量对抗白蚀、修复古建、开启通路 → 走向皇城通天塔。

### 2.2 操作机制

| 操作 | 说明 |
|---|---|
| 2.5D 场景移动 | 方向键 / 虚拟摇杆 |
| 调查 | 点击调查物体、聆听呓语 |
| 解密交互 | 拖拽构件归位、跟随墨线拓印 |
| 心舍 | 滑动浏览符诏 + 点击抉择（抹除需二次确认） |
| 战斗 | 点击释放技能（斗拱/飞檐/藻井） |

### 2.3 核心规则（目标、胜负与结算）

- **识海（心舍）容量**：初始 5 道墨灵，章节推进可扩充至上限 7 道。
- **拓印规则**：获得新墨灵符诏时必须先择一旧记忆抹去（容量满时）。
- **胜负条件**：解密成功/战斗获胜 → 修复古建、推进；解密失败/战斗失败 → **侵蚀度**上升；侵蚀度达 100% → 事件失败。
- **结算方式**：事件星级 1–3 星 = 修复度 + 白蚀清除度 + 记忆保留度综合评定；无金币，进度资源为「**墨痕**」（解锁章节/回溯重试）。
- **记忆账册**：章节界面展示「记住/遗忘」清单，形成玩家专属的叙事档案。

### 2.4 失败与重试机制

- 无生命值，改用「侵蚀度」（0–100）：解密失败 +10，战斗失败 +15，战斗中受伤 +5/次。
- 侵蚀度达 100%：事件失败 → 该古建的这段记忆**永久消散**（场景进入「残迹」状态，剧情分支改变，无法再访原貌）。
- **侵蚀三阶段**（补丁·建议采纳，服务评分点 1.4）：**浸**（0–40：建筑褪色、声音减弱）→ **蚀**（40–70：构件崩解、呓语失真）→ **竭**（70–100：进入「残迹」、记忆永久消散）。视觉随阶段变化。
- 重试：消耗 1 点「墨痕」回溯至事件起点；已拓印的记忆保留。

### 2.5 难度成长曲线

| 章节 | 教学/机制 | 解密复杂度 | 白蚀强度 |
|---|---|---|---|
| 第一章 社庙 | 教学（拓印、斗拱、藻井净化、心舍） | 单步拼合 | 弱（1 波） |
| 第二章 戏楼 | 引入抉择 + 飞檐远程 | 多步谜题 | 中（1–2 波） |
| 第三章 牌坊 | 共鸣连携 + 条件谜题 | 条件谜题 | 较强（2 波） |
| 第四章 通天塔 | 全机制 + 终极抉择 | 综合谜题 | 强（2–3 波） |

### 2.6 时长规划（对齐 Task03）

- 单事件（关卡）：5–8 分钟（解密为主）。
- 总量：4 章 × 每章 2–3 事件 ≈ 30–50 分钟。
- **Task03 Demo**：完整「社庙」章节（约 10 分钟），满足赛题「≥3 分钟可体验内容」并留余量。

## 三、系统设计与世界观剧情【评分点 1.3，5 分】

### 3.1 角色系统

- **主角**：王朝最后的「拓印师」，手持空白《檐下谱》（名字【待确认】，可无名/玩家自定义）。
- **无传统 NPC**：剧情通过「古建呓语」触发；角色形象灵感来自官方「灵画师」素材（匠魂拟人化呈现）。
- 成长：通过新墨灵符诏（技能）与心舍容量扩充成长，无等级体系（叙事驱动）。

### 3.2 经济与数值系统（初版数值表）

| 数值 | 定义 | 初版数值 |
|---|---|---|
| 识海容量 | 心舍可承载墨灵数 | 初始 5 → 社庙末 6 → 戏楼末 7（上限）。世界观理由（补丁·建议采纳）：墨灵与承载者共鸣，承载越多自身记忆越被稀释——「记别人的事，忘自己的事」；上限 7 与「通天塔七层」传说呼应 |
| 侵蚀度 | 事件失败风险条 | 0–100（浸 0–40 / 蚀 40–70 / 竭 70–100）；解密失败 +10 / 战斗失败 +15 / 受伤 +5；达 100 事件失败 |
| 墨痕 | 进度资源 | 事件 1 星=1、2 星=2、3 星=3；回溯重试耗 1；章节解锁耗墨痕（【待确认】具体值） |
| 战斗时长 | 单场轻战斗 | 30–60 秒 |

> 数值原则：无传统货币、无体力，避免惩罚性设计；「侵蚀度+残迹」取代失败挫败感，把失败转化为剧情分支体验。

### 3.3 背包与道具系统（心舍）

- **背包即「心舍」**：容量 5–7 道墨灵符诏，符诏=解密工具+战斗技能（双重用途）：
  - **斗拱 → 承重**：解密（压机关/承重归位）；战斗（防御/护盾）。
  - **飞檐 → 穿透**：解密（远程触发/跨越）；战斗（远程攻击）。
  - **藻井 → 净化**：解密（清除污渍/显影墨线）；战斗（清除白蚀/治疗）。
- 抹除旧记忆有视听代价（画面褪色、对应音效消失），并在「记忆账册」中记录。
- **抹除的三重代价**（补丁·建议采纳）：①视听——对应音效/色调消失；②剧情——记忆回归或消散，影响分支与「残迹」；③系统——若被抹记忆为技能来源，技能**仅做叙事性弱化**（避免产生"最优解"压力，【待确认】）。

### 3.4 世界观（时间 / 地点 / 背景）

- **时间**：架空古风「墨痕王朝」。
- **地点**：乡村社庙 → 城镇戏楼 → 皇城「通天塔」，沿途有风雨廊桥、牌坊等古建。
- **背景**：墨痕王朝依靠「建筑意」维系文明——每座宫殿、亭台、廊桥都承载建造者的「匠魂之忆」（情感、秘闻、失传技艺），化作肉眼不可见的「墨灵」。王朝正遭「墨竭之劫」：「白蚀」蔓延，被侵蚀的古建褪色失忆、人民遗忘来历。唯一能对抗白蚀的是拓印下来的「墨灵符诏」，但识海有限——每拓印一道新记忆，就必须亲手抹去一道旧记忆。
- **白蚀成因链**（补丁·建议采纳）：**遗忘 → 墨灵失载（断墨）→ 逆结晶为白蚀 → 侵蚀邻近建筑 → 更多记忆被抹除 → 循环加速（墨竭之劫）**。白蚀不是外来敌人，而是「被遗忘」的具象化；对抗白蚀=对抗遗忘。
- **主角动机**：从濒临崩塌的「风雨廊桥」醒来，沿古建脉络拓印记忆、对抗白蚀、探寻「墨竭之劫」真相。
- **拓印资格**（补丁·建议采纳）：主角失忆不是剧情漏洞，而是「无我识海」的资格条件——空白《檐下谱》与空白识海互为表里；普通人有记忆定见，无法承载他人记忆。

### 3.5 剧情主线（四章结构与结局抉择）

| 章 | 场景 | 叙事核心 | 机制引入 | 关键抉择点 |
|---|---|---|---|---|
| 序章 | 风雨廊桥 | 醒来、获得《檐下谱》、学会拓印 | 教学 | — |
| 一 | 社庙 | 香火记忆、修复主梁 | 斗拱 | 教学性小抉择 |
| 二 | 戏楼 | 戏班绝响（地方戏记忆） | 飞檐 | 为拓印「戏班绝响」，须抹去「童年社戏」记忆 |
| 三 | 牌坊 | 「名」与「实」：功名、家族与无名匠人 | 共鸣连携（藻井已在社庙获得） | 抹去无名匠人之忆以保全大匠之名？ |
| 四 | 通天塔 | 白蚀源头=初代拓印师的「终极记忆」——他为建立永恒秩序抹去所有战乱与悲痛记忆并封存于塔；**塔最终被遗忘、整体逆结晶**，成为白蚀源头（补丁·建议采纳：两说合一） | 全机制 | **终极抉择：将哪些记忆拓印回世界** |

**结局设计（建议 3 个，【待确认】）**：
1. 「千秋尽墨」——拓印回所有记忆，世界恢复完整但重回伤痛；
2. 「无垢之城」——保持遗忘，秩序永恒但世界苍白；
3. 「檐下折中」——只记住值得记住的（由玩家在抉择中决定，达成隐藏条件）。

## 四、解密谜题体系设计（重点展开 ①）

### 4.1 谜题类型清单

| 类型 | 玩法描述 | 文化表达点 |
|---|---|---|
| A 墨线拓印 | 跟随/重现墨线轨迹，在正确位置完成拓印 | 传统拓印工艺 |
| B 构件归位（榫卯） | 拖拽斗拱/构件拼合归位，开机关 | 榫卯结构（燕尾榫、斗与拱） |
| C 纹样识别 | 识别藻井/檐角纹样、牌坊形制等级 | 藻井图案、四柱三间等知识 |
| D 条件谜题 | 多技能组合：斗拱压住+飞檐远程触发+藻井净化显影 | 建筑构件协作意象 |
| E 抉择之问 | 心舍容量抉择（情感机制，非逻辑谜题） | 记忆伦理主题 |

### 4.2 谜题与技能/古建对应表

| 章节 | 主要谜题 | 主要技能 |
|---|---|---|
| 社庙 | A 拓印 + B 单步归位 | 斗拱（承重） |
| 戏楼 | B 多步 + C 纹样 | 飞檐（穿透） |
| 牌坊 | C + D 条件谜题 | 藻井（净化）+ 共鸣连携 |
| 通天塔 | A–D 综合 | 全技能 |

### 4.3 难度曲线

单步拼合 → 多步谜题 → 条件谜题（双技能联动）→ 综合谜题（全技能+限时/限次条件）。

### 4.4 数值初版总表（汇总）

| 项 | 值 | 备注 |
|---|---|---|
| 心舍容量 | 初始 5，上限 7 | 章节末扩充 |
| 侵蚀度 | 0–100；+10/+15/+5 | 达 100 事件失败（残迹） |
| 墨痕 | 星级 1/2/3 → 1/2/3 点 | 回溯耗 1；解锁章节耗墨痕（具体【待确认】） |
| 战斗 | 每场 30–60 秒，1–3 波 | 波数随章节递增 |
| 单事件 | 5–8 分钟 | 解密为主 |
| 事件星级 | 修复度+白蚀清除度+记忆保留度 | 1–3 星 |

### 6.2 五个推演场景（每场景附可直接使用的提示词模板）

**场景 1：世界观自洽**
- 推演目标：补全「建筑意」体系（记忆如何承载、墨灵形成与消散、白蚀传播机制）。
- 提示词模板：`我正在设计一款国风解密游戏《檐下千秋》，世界观如下：【粘贴背景故事】。请以世界观架构师身份，检查该设定的逻辑漏洞并补全规则：建筑如何承载记忆？墨灵如何形成与消散？白蚀如何传播？给出自洽性分析与 3 条改进建议。`

**场景 2：核心规则（心舍抉择）**
- 推演目标：识海容量上限与「抹除记忆」的惩罚/补偿设计，如何不劝退玩家。
- 提示词模板：`我的游戏核心机制是：识海容量有限（初始5上限7），拓印新记忆必须抹去一道旧记忆，抹除有视听代价。请推演该机制的玩家体验风险（挫败感/选择瘫痪），并给出 2-3 版惩罚与补偿方案及推荐。`

**场景 3：技能平衡**
- 推演目标：斗拱（防御）/飞檐（远程）/藻井（治疗）对白蚀敌人的克制关系与数值。
- 提示词模板：`我设计了三技能双用途体系：斗拱=承重/防御，飞檐=穿透/远程攻击，藻井=净化/治疗。请设计白蚀敌人类型（1-3 波递增）与技能克制关系表，并给出战斗时长 30-60 秒内的数值建议。`

**场景 4：关卡结构**
- 推演目标：四章节奏、叙事节点与记忆抉择点分布。
- 提示词模板：`请为四章结构（社庙→戏楼→牌坊→通天塔）设计关卡节奏表：每章 2-3 个事件、谜题类型分配、叙事节点与记忆抉择点位置，确保每 5-8 分钟有一个情绪高点。`

**场景 5：解密谜题**
- 推演目标：谜题类型与难度曲线适配 2.5D 场景。
- 提示词模板：`请基于中国传统建筑元素（榫卯、斗拱、飞檐、藻井、墨线拓印）设计 10 个解密谜题，难度从单步到条件组合递增，并标注每个谜题的文化知识点。`
