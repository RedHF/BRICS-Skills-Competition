# 客户端

使用 Godot 4.5.2。发布 EXE 及完整运行方式见上级 `启动客户端.md`。

2026-09-15 可玩性修复：探索支持主回车和小键盘回车调查；调查中打开设置、心舍等页面后可恢复现场；剧情回顾按所选任务显示背景。新增 `tests/playability.gd` 覆盖字体、界面边界、页面恢复和音频设置，十任务脚本改用实际画布鼠标输入。详见 [验证记录](../验证记录/2026-09-15-可玩性/README.md)。

2026-09-14 内容 v10，540×960 竖屏布局，固定五项底部导航和战斗操作栏；设置中可切换全屏，宽屏居中阅读。新资源位于 `assets/imported/` 与 `assets/voice/`；184 段配音覆盖剧情和心舍，翻页和离开页面会停止前一段。第三项技艺飞檐在戏楼开台获得，随后迎战小首领。战斗固定键位：1 挥墨、2 斗拱、3 藻井、4 飞檐、5 闪身（支持数字小键盘）。详见上级 `2026-09-14-素材配音与首领更新.md`。

生成美术资源位于 `assets/generated/`。卷轴图用于启动背景；廊桥、社庙庭院和白蚀战斗图由服务端目录的 `art.background` 按事件加载。调查场景会保持图片比例并居中裁切，同时叠加侵蚀褪色与裂纹反馈；心舍展示按原比例保留的竖幅符诏，战斗页使用固定两列操作栏，移除了裁切素材表的徽记条。

`battle_arena.gd` 绘制敌人、血量、攻击预警和技能反馈。`main.gd` 负责地图、事件、心舍、战斗和账册；`trace_canvas.gd` 采集鼠标笔画并绘制同服务端规格一致的容差带；`network_client.gd` 负责 HTTP 边界错误；`data_repository.gd` 用稳定 ID 读取服务端目录。

客户端不携带谜题文字答案，也不在断网时模拟奖励。内容全部由本地 `/api/v1/catalog` 提供，运行状态以随客户端启动的本地服务端为准；无需登录、注册或网络连接。

`tests/integration.gd` 覆盖序章和完整社庙，使用实际画布输入事件并加入手部偏移，验证失败笔画标记和单笔修正、实际攻击/护盾/净化/冷却/失败、语音播放进度与暂停；战斗时钟在测试中加速。该测试脚本不导出到发布程序。

`export_presets.cfg` 配置 Windows x64 可执行文件及嵌入资源。构建机需要 Godot 4.5.2 和同版本 Windows 导出模板；用户运行发布版不需要这些工具。

开屏 Logo 源文件为 `assets/logo.svg`，`logo.png` 用于 Godot 引擎启动画面。客户端启动后由本地配套服务创建或恢复匿名玩家档案，直接进入地图与剧情。开发档案保存在服务端 `data/save.json`，发布版使用 Godot 用户目录的 `save.json`；不上传云端；网络层只发送本机 JSON 请求，不保存账号令牌或登录凭证。

拓印成品使用 `assets/rubbings/*.png` 的预生成静态图片，每个墨灵对应唯一文件。运行时画布仅用于校验笔画和显示临时轨迹，不会实时渲染收藏图或调用 image2.5 生图 API。图片生成失败时显示“待装裱”，不阻塞玩法。

`skill_scene.gd` 与 `pattern_option.gd` 呈现场景目标和图式辨认；`ink_figure.gd` 绘制人物剪影；`soundscape.gd` 播放 assets/audio 原创合成音频，生成脚本位于上级联调脚本。新增 tests/review_journey.gd 验证完整十任务的界面输入。

`dialogue_stage.gd` 统一开场、回顾及失败演出，拦截窗口点击，管理淡入和逐字动画；上一句/跳过/返回不穿透到底层。`tests/narrative.gd` 验证真实点击、失败变体、续读、九句门槛与免费回溯。飞鸟山与首次通关呓语由公开目录提供。
