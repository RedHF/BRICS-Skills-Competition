# 《檐下千秋》章节叙事脚本（草稿 v0.1）

> 配套 `LLM-tmp/01-策划案/檐下千秋-游戏策划案草稿.md`。
> 标注：【实】= 完整演出文本；【纲】= 大纲级（后续细化）。
> 设计原则：无传统 NPC，全部剧情经「古建呓语」传递；每次抉择都进入「记忆账册」，为第四章回收铺垫。
> Task03 Demo 范围 = 序章 + 第一章社庙（约 10 分钟，满足赛题 ≥3 分钟要求）。

## 序章 · 风雨廊桥【实】

**场景设定**：暴雨初歇，半塌的风雨廊桥横跨溪谷。桥身一半完好，一半被「白蚀」侵蚀成灰白色。拓印师倒在桥心，身下压着一本空白《檐下谱》。

**开场演出**
- 黑屏渐亮，雨声入耳，白蚀蔓延的灰白像墨汁褪色一样爬过桥栏。
- 主角起身（教学：移动）。桥心石板上留有刻字「平安」二字，正在褪色。
- 第一次呓语（古建呓语，无 NPC）：*「桥记着送别……也记着归来。香客、货郎、赶考的书生……他们都从桥上走过。桥老了，记得的东西越来越多，越来越多……」*
- 教学 2：走近桥栏「调查」；跟随系统提示完成第一次「墨线拓印」——沿「平安」笔画轨迹滑动，拓印进《檐下谱》。

**谜题 0-1（教学 · A 墨线拓印）**
- 目标：完整拓印「平安」二字（笔画顺序自由，漏笔即失败）。
- 失败反馈：墨线散开、侵蚀度 +10（教学提示说明规则）。

**获得墨灵**：`【檐·平安】斗拱系`——承重（解密：压机关；战斗：护盾）。

**战斗 0-1（教学）**：白蚀化为一团灰影扑来（1 波，30 秒）。教学：点击技能键释放「承重」抵挡 → 白蚀退散。
- 战斗后提示：侵蚀度、墨痕、心舍三项界面说明。

**结尾**：桥身修复回原色，桥头雾散，露出一条通往山间社庙的土路。呓语尾句：*「往前走吧。社庙的香，好像很久没有点起来了……」*

## 第一章 · 社庙【实】——Task03 Demo 主体（约 10 分钟）

**章目标**：修复社庙三处记忆；学会心舍抉择；章末识海容量 5→6。
**场景总览**：山间社庙，三进小院：正殿（事件 1-1）、侧厢（事件 1-2）、前坪（事件 1-3）。

### 事件 1-1「香火断」【实】

| 项 | 内容 |
|---|---|
| 场景 | 社庙正殿。香炉倾倒、主梁断裂半悬、牌位蒙尘 |
| 事件目标 | 归位主梁斗拱，重燃香火记忆 |
| 呓语 | *「春社那天，全村的人都来。香要烧得旺，庄稼才肯长。后来……后来香断了，村子也就慢慢空了。」* |
| 调查点 | ①香炉（铭文：某年立）②断梁（榫口完好）③牌位（村名可辨认） |
| 谜题 | B 构件归位（教学级单步）：把散落的三块斗拱构件拖回主梁榫口（榫卯对齐提示线） |
| 失败反馈 | 构件放错位置：墨迹扩散提示，侵蚀度 +10 |
| 获得墨灵 | `【社·承香】斗拱系`（承重；心舍 2/5） |
| 战斗 | 白蚀成批（1 波，30 秒），教学轻战斗完整流程 |
| 结算 | 1-3 星：修复度 + 白蚀清除度 + 记忆保留度；墨痕 +1~3 |

### 事件 1-2「檐下客」【实】

| 项 | 内容 |
|---|---|
| 场景 | 社庙侧厢。供桌上一碗冷饭、一领旧蓑衣；门楣匾额缺字 |
| 事件目标 | 拓印残缺匾额，找回「檐下不拒客」的记忆 |
| 呓语 | *「下雨天，行路的、要饭的，都到庙檐下躲雨。庙祝说：檐下不拒客。一碗冷饭，也分半碗。」* |
| 调查点 | ①匾额（「□安」缺一字）②冷饭碗 ③旧蓑衣 |
| 谜题 | A 墨线拓印：匾额「□安」——先按字形推理缺字（选项：平/宁/保），再沿完整字形拓印。正确答案「宁」（呼应序章桥刻「平安」→「宁安」） |
| 获得墨灵 | `【社·宁安】斗拱系`（承重；心舍 3/5） |
| 战斗 | 无（纯解密事件，调节节奏） |
| 结算 | 同星级规则 |

### 事件 1-3「社鼓声」【实】——首次心舍抉择

| 项 | 内容 |
|---|---|
| 场景 | 社庙前坪。社鼓蒙灰，鼓面白蚀斑驳 |
| 事件目标 | 净化鼓面、拓印鼓纹，唤醒春社鼓声 |
| 呓语 | *「鼓一响，社就开了。小孩儿追着鼓点跑……后来鼓声停了，连孩子的声音也听不见了。」* |
| 调查点 | ①社鼓（白蚀斑覆盖纹样）②鼓槌（压在鼓下）③坪中香樟（挂满旧红绳） |
| 谜题 | 组合：先用新教学技能「净化」（藻井系）清除鼓面白蚀斑 → 显影出鼓纹墨线 → 再按墨线拓印 |
| 获得墨灵 | `【社·回春】藻井系`（净化；心舍 4/5） |
| 战斗 | 白蚀强化（1 波，45 秒），含一次「侵蚀斑」群体减速机制 |
| **抉择点** | 拓印「社鼓声」需要第 5 格，识海已满 4/5——但鼓声记忆格外重，需**两格**空间。系统列出可抹去的候选项（序章「檐·平安」/ 事件 1-1「社·承香」/ 事件 1-2「社·宁安」三选一），并预告代价（被抹去记忆对应的场景音效与色调将在账册中变灰）。**教学性软抉择：选哪道都能推进，但记忆账册从此不同。** |
| 结算 | 星级 + 墨痕；章末演出：社庙恢复香火，识海容量 5→6 |

**章末呓语（引出第二章）**：*「东南方……有锣鼓声。戏楼要开场了。可是那锣鼓，怎么越敲越远……」*

## 第二章 · 戏楼【纲】

- **主题**：戏班绝响——「记住绝唱，就要抹去自己的童年社戏」。
- **机制**：引入飞檐（穿透/远程触发）；多步谜题；第一道**重大抉择**。
- 事件 2-1「开场锣」：戏楼后台，行头箱错位。谜题：纹样识别（戏袍纹样与角色行当归类）。获 `【戏·行腔】飞檐系`。
- 事件 2-2「名角儿」：舞台中央，失落的台步记忆。谜题：多步构件归位（台步点位+布景板对位）。**核心抉择**：为拓印「戏班绝响」（双格记忆），必须亲手抹去「童年社戏」——玩家若拒绝，事件以「残迹」收场、戏楼永远空场。
- 事件 2-3「散场」：空场战斗 1-2 波（远程机制教学）。章末：戏楼重生，容量 6→7（上限）；呓语引出官道尽头的牌坊。

## 第三章 · 牌坊【纲】

- **主题**：「名」与「实」——功名、家族与无名匠人。
- **机制**：引入共鸣连携（双技能组合条件谜题）；藻井净化进阶。
- 事件 3-1「四柱三间」：牌坊形制文化谜题（牌坊等级：四柱三间/两柱一间；文字题+构件归位）。获 `【坊·无名】飞檐系`。
- 事件 3-2「无名匠」：牌坊背面无名的营造记录。条件谜题（斗拱压住+飞檐远程触发）。**抉择**：抹去无名匠人的记忆以保全大匠之名，还是留下无名之实？
- 事件 3-3「旌表」：白蚀强袭 2 波。章末呓语：皇城方向，黑云压顶，通天塔现身。

## 第四章 · 通天塔【纲】

- **主题**：白蚀源头 = 初代拓印师的「终极记忆」——他为建立永恒秩序，主动抹去了所有战乱与悲痛记忆，导致世界失衡。
- **机制**：全机制综合谜题 + 记忆账册回收。
- 事件 4-1「登塔」：综合谜题（拓印+归位+条件，限次尝试）。
- 事件 4-2「千层墨」：塔内历代拓印师记忆长廊——按玩家全程的「记忆账册」回放其所有抉择（叙事回收）。
- 终局「终极抉择」：决定将哪些记忆拓印回世界 → **三个结局**：
  1. 「千秋尽墨」：拓印回全部记忆——世界完整，但重回伤痛；
  2. 「无垢之城」：保持遗忘——秩序永恒，世界苍白；
  3. 「檐下折中」：只拓印回玩家在全程抉择中选择守护的记忆——达成隐藏条件。
