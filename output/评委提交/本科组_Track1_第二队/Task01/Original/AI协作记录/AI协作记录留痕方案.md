## 二、留痕方式与工具操作（已定：DeepSeek Harness + Codex + 截图）

### 2.1 会话导出（主证据，每轮必做）

**DeepSeek Harness（Web GUI）**
1. 在会话页使用页头「导出」按钮，或在输入框输入命令 `/export`；
2. 浏览器下载 `dsh-session-<会话ID>.zip`（包含会话树与附件）；
3. 解压后放到 `导出/`，重命名为 `YYYY-MM-DD_轮次_DSH_目的/`（保留 zip 原件）。

**Codex CLI**
1. 版本 ≥ v0.148.0（2026-08-19 起内置 Markdown 导出）：用 `codex export <session-id>` 导出会话记录；
2. 旧版本：安装第三方工具 [codex-export](https://github.com/jinghan23/codex-export)（npm，可将 Codex CLI 会话导出为 Markdown）；
3. 导出文件放 `导出/`，命名 `YYYY-MM-DD_轮次_Codex_目的.md`。
   （具体命令以你本机安装的 Codex 版本为准，运行 `codex --help` 确认 export 子命令。）

### 2.2 全程截图（辅证，兜底）

- 每个 AI 会话从提问到回答完整截图（导出功能失效时的兜底证据），文件名 `YYYY-MM-DD_轮次_工具_目的.png`。
- 截图前隐藏与比赛无关的个人信息；涉及账号密码的界面打码。

### 2.3 版本保留

AI 初稿与人工修改稿分别保存，放 `版本/`，命名 `v1-AI初稿` / `v2-人工修订`。

### 2.4 来源标注

策划案里每条核心创意标注来源：`AI 生成` / `人工构思` / `人机协作修改`（用脚注形式，正好满足「关键词脚注解释」的排版要求）。

## 四、关于「70% AI 占比」的说明

- 赛题、评分标准、技术规程三份官方 PDF 中均**未出现**明确的 70% 数字；技术规程仅有「确保作品 AI 工具生成素材的最终占比」的表述。
- 结论：**按本方案全量留痕**（截图+导出+版本+标注），无论赛方最终如何界定占比，都有佐证；如技术说明会或 QQ 群有明确口径，以官方口径为准。
