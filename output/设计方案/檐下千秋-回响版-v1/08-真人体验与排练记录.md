# 回响版初见体验与排练记录

更新：2026-11-05。本表没有预填成功结论。当前测试程序为 **A13／A-preview13b**；09 的新文案和版式尚未接入。测试者只看第 3 节开场语，不先阅读策划、解法、复审报告或本表后续的分析标准。

## 1. 已有反馈与本次目标

2026-11-04 用户先后指出缩放、旋转拖曳、文字、白蚀形象、音效、步态、灰色确认框和独立进度入口问题。A12/A13 已有对应修复及自动检查；尚未收到完整的新版初见复测。已有反馈不等于多人样本，也没有可补填的耗时或听感数据。

本次验证：能否自己推进；能否解释一次接合依据；能否理解所选对象与后果；能否区分实际用途与私人回声；章末扩容会怎样影响对刚才选择的理解。

建议先 3 位未读策划、偏好故事或轻解谜的体验者诊断，再用 2 位新体验者复核最主要的修改。这是小规模定性计划，不作统计代表性或赛事通过率声明。测试者不需要按设计者期待感到悲伤。

## 2. 主持人准备

使用 [当前包说明](../../../dist/回响版-当前预览.md) 中的 A-preview13b，核对完整解压后仅开一个窗口。**当前主页没有独立片段入口**。从“开始旅程”正常进入；已有进度时显示“继续旅程”，不能将它当成新旅程入口。先解决测试起点，不让新体验者接着别人已确认的选择做“初见”。不要覆盖原有玩家存档。

主持人先在独立的测试环境确认新旅程起点可用，例如另一个 Windows 测试用户，记录方式及起点。仅把程序复制到另一个目录不会隔离存档：本版仍读取当前 Windows 用户的 `%APPDATA%/Godot/app_userdata/檐下千秋/echo-v1-save.json`。不删除个人进度，不在测试中临时改存档伪造容量。若只能从社庙中段开始，标为“片段理解测试”，不能用于证明玩家记得前面三段或有情感取舍。

先确认屏幕、输入、声音和录屏安排。正文按正常窗口阅读，使用计划中的耳机或扬声器。慢读、思考、主动试听不算卡住。约 25—40 分钟仅是旧目标，本次记录实际时间，不要求赶完。

## 3. 给体验者的开场语

“请按自己的想法体验这段游戏。你可以随时停下，也可以说说正在想什么。遇到不明白的地方就按平时会做的方式尝试；我会先记录，需要帮助时再提供。我们在看游戏哪里需要改，不评价你做得好不好。”

不要事先解释榫口答案、三段旧记忆的意义、归档将保留什么，或询问是不是会被扩容欺骗。游戏自己解释到什么程度，正是本次观察对象。

## 4. 第一次操作：只记录，不教解法

| 时刻 | 记录行为、原话和发生时间 |
| --- | --- |
| 初次进入：先看哪里、先点什么 | |
| 接梁：选件、转向、查看、返回的实际过程 | |
| 一次错误后做了什么，反馈是否改变下一次判断 | |
| 摆碗：想放哪里，是否被不明白的门槛阻断 | |
| 拓显：是否知道作用对象，是否主动使用辅助输入 | |
| 选择前：查看了哪些回声，是否找到另一种处理方向 | |
| 确认前：是否知道将处理哪一段，是否误触 | |
| 选择后：自己注意到什么，是否主动试着敲鼓 | |
| 章末扩容：原话、表情所对应的行为，不推测内心 | |
| 突兀的声音、动作、物件或阅读困难 | |

出现明确无进展约 60 秒，或体验者主动求助时，先问“现在想做什么，哪里不确定”。若继续求助，先请其使用游戏内提示；再需要时才给方向，最后才说明具体操作。记录介入时间与原话。不把得到解法后完成写成“独立理解”。

若不能继续、误操作不可恢复、保存失败或确认对象与预期不同，停止该项并记录复现过程。不要靠口头带过继续计作完成。

## 5. 两次短提问，避免事后解释污染

接梁完成后问：“你刚才是根据什么决定这样放的？”记录回答是否来自形状/刻痕、阶段说明、试遍候选或主持人提示。不要求说出古建术语。

取舍确认后、章末扩容前，让体验者先自由回答：“你刚才做了什么决定？你觉得它改变了什么？”然后自然继续到扩容，再问：“接下来你原本以为会怎样，现在有什么不同？”不先说正确答案。

离开社庙后再问以下问题，先记原话，再做解释：

- “你最记得哪个物件或哪件事？为什么？”
- “刚才的选择里，你看到了哪些可选做法？最后为什么选这个？”
- “如果回到那座建筑，你觉得还有什么，什么发生了变化？”
- “哪一处你以为能做，但游戏没有让你做？”
- “你会想继续吗？是什么让你这样想？”

追问只能沿体验者刚才说过的内容，避免“孩子的声音消失了你难过吗”这类给出答案和情绪的问题。没有注意到差别就是有用结果，不补讲后再把回答算作初见成功。

## 6. 主持人判读与下一次修改

下面是分析标准，不能作为体验前说明。目标是诊断，不给体验者评分。

| 观察结果 | 下一步 |
| --- | --- |
| 知道要修梁，但不会选件/转向/返回 | 优先改操作提示或入口层级，保留观察判断 |
| 能通关，只能复述步骤，不知道对应依据 | 用 09 的物证文案和提示分层做下一版；不要增加谜题步骤 |
| 没意识到能保留现有回声，或分不清将归档哪段 | 优先采用 09 的两种同级方向和对象确认规格 |
| 误以为归档删除事实、真实建筑、技能或通关资格 | 优先改局部前后反馈及确认边界，再找新体验者复测 |
| 理解归档但只当音频收藏，无法说出任何人在此做过什么 | 修改事件和物件回应；单靠增加说明文字不足以解决 |
| 扩容后自发表示刚才的取舍没有必要或被反悔 | 记录原话；比较延后取得新承载能力的方案，并重审选择密度 |
| 明白规则、理由清楚但不留恋某段回声 | 合法偏好，不能据此认定设计失败或强迫悲伤 |
| 安静时听得到，正常环境声下辨认不了私人回应 | 优先调声部层次；静音下另查等价视觉/字幕提示 |

任何一次不能继续或归档对象误解，都先修复再测试。两位体验者出现同类理解障碍时，将它列为首要修改；这是工作触发线，不是统计显著性。

每轮只改最能解释现象的一到两项；复测用新体验者，以免他们已经记住答案。旧体验者可复核手感和偏好，但单独标记。保留新旧原话和失败记录。
