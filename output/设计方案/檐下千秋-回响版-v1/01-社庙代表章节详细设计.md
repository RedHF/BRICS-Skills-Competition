# 社庙代表章节：逐场景实施设计

版本：v1.0，2026-11-02；完成边界校正：2026-11-05。全局规则以 [00-改版总方案](./00-改版总方案.md) 为准。本文件覆盖 A 版重点章节，表示设计目标；实际已实现、替代与缺口见 [05-实施进度与自评](./05-实施进度与自评.md)，不能将本文件中的演出目标直接当作实机成果。最新提示层次、事实来源和选择版式修订见 [09-人工测试前设计定稿](./09-人工测试前设计定稿.md)，其中新文案尚未接入 A13。

## 1. 章节目标与入口

章节名：**一檐容人**。保留原任务名“香火断／檐下客／社鼓声”，分别作为章节内段落标题。

主题：共同修起的屋檐，曾接纳一个陌生人，也曾聚起一院子的人。主角能修复它的用途，无法把每一次独特回应都带在身上。

初次体验目标八至十二分钟；从完整旅程自然进入时，玩家已完成 E01，心舍默认有“檐·平安”1/3，已学斗拱。若玩家此前主动归档平安，按实际心舍继续，不为凑容量偷偷补入记忆。

本章三处场景各自取现有背景：正殿、侧厢、前坪。点击空间连接物切换：正殿侧门 → 侧厢门槛 → 前坪树影。完成事件可退出；回来恢复未完成动作，不重播全部开场。

章内不出现独立伤害战斗、星级、墨痕或“必须调查三个点”的计数。没有可移动 NPC；人物在往事中通过物件、手影和声音存在。

## 2. 场景一：正殿“香火断”

### 2.1 场景构图

现有正殿背景保留建筑主体。镜头中明确呈现倾斜梁端、两处榫口和临时撑木；地面有三件可用构件、一件榫头残缺的旧件。香炉放在次要位置，避免玩家误以为只需点香。

必需调查物件：梁端榫口、捐木记号。可选物件：倾倒香炉。不同物件只在靠近或主动查看时出现轮廓提示，不常驻三个大文字标记。

### 2.2 状态流程

| 状态 | 玩家看到与听到 | 有效操作 | 下一状态／保存点 |
| --- | --- | --- | --- |
| T00 入殿 | 雨水断续落在旧碗旁；梁端墨线断开 | 走近/点击梁架；可略过短对白 | T01 |
| T01 观察 | 当前目标“看看梁为什么没能合拢” | 查看梁口、查看木件记号，顺序不限 | 必需线索齐后 T02；调查状态即时保留 |
| T02 靠近 | 视角切到同一梁端；原环境仍可在边缘认出 | “开始修复” | T03 |
| T03 承架 | 梁倾斜，候选可看不可安装；临撑有明确落点 | 选择斗拱·承架，再点临撑锚点 | T04；保存承架已完成 |
| T04 配合 | 三处槽口与四件候选；旧记号相互对应 | 选件、旋转、查看端部、拖放或点击安装 | 左右件均就位后 T05；逐件保存 |
| T05 合拢 | 中部合拢位置显出完整轮廓 | 安装中部件；可先预览，不可越过左右前置 | T06；保存结构完成 |
| T06 卸撑 | 梁架已有完整连接，临撑仍在 | 点击“试着撤下临撑” | T07；不要求玩家猜新操作 |
| T07 回应 | 梁落稳，雨水避开碗；旧捐木记号连成一组 | 观察 2 秒后可继续或提前略过演出 | T08 |
| T08 显影 | 社·承香拓片出现；播放现有对应回声 | 收入心舍／只留记录 | 保存 E02 选择和完成，再 T09 |
| T09 侧门 | “饭凉了，也请进来坐”的现有声音从侧门传来 | 点击侧门或“前往侧厢” | G00 |

### 2.3 榫构谜题的唯一解与判定

这是游戏化梁架机关，不把三件抽象件命名为完整真实斗栱构造。正式物件在制作前先画无纹理轮廓，验证凸凹关系；名称使用“左接件／右接件／中部合拢件”。

| 构件 ID | 玩家可观察的形状依据 | 目标 | 朝向与前置 |
| --- | --- | --- | --- |
| JOIN-L | 单侧凸榫、两道短刻痕，对应左槽的凹口与刻痕 | SLOT-L | 初始转反；旋转 180°后正确；已承架 |
| JOIN-R | 与左件不同的肩部凹口、一道斜刻痕 | SLOT-R | 初始正确；0°；已承架 |
| JOIN-C | 双端接合轮廓，与左右就位后露出的中部凹口相合 | SLOT-C | 0°；L 与 R 均完成 |
| JOIN-X | 榫头缺损，不能形成完整接合；存在相近木色 | 无 | 查看端部可见缺损，无合法安装位置 |

正确依赖：承架 → L/R 任意先后 → C → 卸撑。木色不能成为唯一答案，形状与记号至少两个线索同时可用。

仅提供 0°/180°两种方向，不增加自由角度摩擦。鼠标抓取区域至少 72×72 逻辑像素；物件中心到目标中心距离 ≤48 时可吸附，但类型、方向、前置均需正确。无合法目标时轻微回弹，已有正确物件保持不动。

键鼠替代：单击选件，点击“转向”，点击槽口安装；Tab 可依次聚焦件、转向、槽口，Enter 确认。拖动不是唯一完成方式。

### 2.4 错误反馈与提示

| 情形 | 现场反馈 | 一句提示 |
| --- | --- | --- |
| 未承架便安装 | 梁端轻晃，物件回到托盘 | “梁还在晃，先让它有个依靠。” |
| 左件转反 | 只突出不相合的榫肩，不整屏报错 | “看看凸口该朝哪一边。” |
| 选到缺损件 | 放大缺口，候选保持可查看 | “这块的榫头缺了一角。” |
| 中部件过早安装 | 左右未完成部位各闪一次 | “它要接住两边，先看看两端。” |
| 点击空处 | 取消选择 | 无额外惩罚或语音 |

三级提示依次指向“榫口和记号”“先承架、再接两端”“明确件与方向”。第三层只在玩家主动点击后出现完整引导。任何错误不增加侵蚀、不限制次数、不清空进度。

### 2.5 修复演出

0.0—0.4 秒：主梁由倾斜离散状态过渡到稳定；0.4—1.2 秒：捐木记号对应亮起；1.2—2.5 秒：雨水由碗旁移到檐外，碗沿出现一段暖光；2.5 秒后回声可继续听或略过。

使用同构图和局部图层，不生成镜头、柱数、香炉位置都改变的另一张“修好图”。木料拼接与旧裂痕保留。减弱动态设置下直接切到稳定态，并保留文字结果。

## 3. 场景二：侧厢“檐下客”

### 3.1 行动逻辑

门外雨线与门内干燥地面形成清楚分界。一碗旧饭位于门内，第二只空碗停在檐外边缘；蓑衣与两双筷子的磨痕说明这里曾接纳陌生人。

谜题目标是“在屋檐下给来客留个位置”。玩家查看旧碗和蓑衣后，将第二只空碗移入门内有效区域。任何不与旧碗重叠、且位于干燥区域的落点都成立，不要求猜一个像素精确位置。有效区域以实际地面画出的干湿边界为依据，不能与屏幕图片不一致。

这次操作是主角对往事的回应，不宣称仅凭摆放一个物件就还原了确切历史。档案分别记录“发现两双筷子磨痕”与“你把第二只碗放入檐下”。

### 3.2 状态流程

| 状态 | 内容 | 判定与结果 |
| --- | --- | --- |
| G00 入侧厢 | 现有客声“那夜我浑身是雨，不敢跨过门槛。他却先把碗推了过来。” | 可先听完或直接观察 |
| G01 观察 | 旧碗与蓑衣可任意查看；磨痕随局部放大清楚出现 | 两个核心物件看过后出现简短目标 |
| G02 留位 | 拖动第二只碗，或选碗后点干燥地面 | 放入有效区且不重叠即通过；檐外落点只回弹 |
| G03 回应 | 门内多一道碗影，雨声稍远；客声完整回应一次 | 保存摆碗完成，习得藻井·显纹 |
| G04 显影 | 社·宁安出现，标准路径此时从 2/3 到 3/3 | 收入／只留记录；不强制三格占满 |
| G05 走向前坪 | 远处响起孩子的半句数拍 | 点击前坪入口；保存 E03 完成 |

摆碗无顺序试错惩罚。误放提示“雨还会落在这里”，点提示显示干湿分界，不直接替玩家摆好。完成后不再播放一场战斗或星级结算。

## 4. 场景三：前坪“社鼓声”

### 4.1 物件与玩法

保留现有前坪背景与鼓。关键物件是鼓面白蚀、三结红绳；树下脚印作为可选记忆线索。藻井作用对象必须是鼓面，不能再用一块通用“白蚀碑面”替代。

此处拓显对象是《檐下谱》感应出的记忆图纹，不是在真实鼓皮上操作纸墨。交互保留传拓“呈现已有纹样”的方向，不要求玩家凭空补画新图案。

### 4.2 状态流程

| 状态 | 画面与动作 | 通过条件 |
| --- | --- | --- |
| D00 看鼓 | 童声“一、二、三”到第三拍前断掉；鼓面纹样不全 | 查看鼓面与红绳；脚印可选 |
| D01 显纹 | 选藻井·显纹，点击鼓面白蚀 | 目标正确；鼓纹由遮蔽态变可辨态 |
| D02 拓显 | 铺开谱页局部，显出鼓纹的三个区域 | 完成以下覆盖规则 |
| D03 听见 | 鼓点与孩子数拍完整响一次，社·回春拓片显影 | 允许重听；此时尚未处理新共鸣 |
| D04 选择 | 按实际容量进入有空位或满额界面 | 明确决定新回声状态；必要时选择旧回声归档 |
| D05 后果 | 展示被归档那段的具体回应退出，再回到前坪 | 选择已经保存；可略过演出，不跳过结果文本 |
| D06 验证 | 玩家敲一下鼓；正常鼓声必定响，是否带孩子跟拍由记忆状态决定 | 不要求节拍准确；让玩家主动听见差别 |
| D07 章末 | 谱页展开，容量由三扩为四；远处一声锣 | 保存 E04 完成和扩容；开放戏楼 |

### 4.3 拓显覆盖规则

三个区域为外环纹、中央纹、旧修补线，各自以固定遮罩定义。指针按住扫过会显出已有纹样；一个像素多次经过不重复累计。每区有效覆盖达到该区面积的 65% 即记为完成，三者全完成才通过。

笔刷直径为画布短边的 9%；离开有效区不累计，也不扣除。按住不移动只显出刷头覆盖的局部，不自动完成全图；按区域保存已完成标记。重新进入时已完成区域保持完成，当前未完成区域可从该区域重新开始。鼠标释放可以随时停笔，没有笔顺、压力和速度要求。

提供“辅助显影”：点击区域后按住 Enter 1.5 秒完成该区；界面显示按住进度，松开保留本次区域内的辅助进度。与鼠标方式同样推进剧情、无额外标记或降级奖励。

拓显合格不等于完全涂满：完成区域保留局部自然纸白与磨损。结果采用固定已核对的纹样图，不把鼠标乱涂永久画进文物。

## 5. 第一次取舍：所有分支

### 5.1 标准满额状态

已持有檐·平安、社·承香、社·宁安三段；新显影社·回春。四个方向均合法：

| 方向 | 最终鲜活共鸣 | 立即演出 | 后续细节 |
| --- | --- | --- | --- |
| 归档平安，带走回春 | 承香、宁安、回春 | 谱页中桥上灯影不再伴随归人脚步；前坪保留孩子跟拍 | 重访桥时个人回声层不再触发；实体桥灯与雨声保持正常 |
| 归档承香，带走回春 | 平安、宁安、回春 | 谱页中捐木记号的手影退出；前坪保留跟拍 | 正殿修复状态保持，个人抬梁回声层停止 |
| 归档宁安，带走回春 | 平安、承香、回春 | 谱页中第二只碗的记忆暖影退出；前坪保留跟拍 | 玩家摆入檐下的真实空碗仍在，客声不再随身回应 |
| 只留回春记录 | 平安、承香、宁安 | 先响一遍刚经历的完整数拍，归档后专属童声退出 | 主动敲鼓仍有正常鼓声，孩子的记忆跟拍停止 |

记忆后果改变的是主角可唤起的感官层，不把个人归档解释成世界中所有人都遗忘。归档旧回声时使用谱页局部预览表现退出，不能把未到场的桥实体突然切成废墟。

### 5.2 界面与文字

顶部：“心舍 3/3 · 新听见一段回声”。新记忆为“社·回春／鼓声唤回相聚的人”；下方列出实际持有的旧回声，每张可查看代表物与一句摘要。小字固定：“记录与手艺会留下，归档的完整回声不再随身响起。”

点击旧候选后显示两段结果：

- 带走：社·回春——孩子会在你敲鼓时跟拍。
- 归档：所选旧回声——具体会停止的声音或影像。

主按钮“带走回春，归档这段回声”；次按钮“只留下回春的记录”；另有“再听一会儿”关闭候选详情但不撤销已看内容。

确认例：“归档檐·平安后，桥的记录与斗拱技艺仍在；那段归人的脚步声将不再被你唤回。确认吗？”按钮“确认归档／再想想”。

“只留记录”同样确认一次，明确将归档的是新回声，不误删旧回声。已确认后重进不重复选择；处于演出中断时恢复到已提交结果，不回到未选择状态。

### 5.3 非标准入口

| 情况 | 处理 |
| --- | --- |
| 实际持有少于三段 | 有空位时可直接带走，也可只留记录；不制造假满额 |
| 先前已归档的旧回声 | 候选列表不出现；记录中可看摘要但不能重新领取 |
| 重访社鼓声 | 展示原选择与现状，不产生新奖励或修改选择 |
| 选择后退出、战斗失败或程序重启 | 已提交选择保持，章末扩容只执行一次 |
| 保存暂时失败 | 不播放“已归档”结果，留在确认界面解释可重试 |

## 7. 保存、恢复与事件完成边界

每个稳定步骤独立保存：看过核心线索、临撑就位、L/R/C 就位、空碗入檐、显纹完成、三个拓显区域完成、记忆处理、事件完成、章末扩容。

不得把“玩家看过归档动画”作为真正修改记忆的时点；应先原子保存选择，再演出结果。不能因动画被跳过漏记扩容或记忆状态。

切换设置、收藏、关卡时保留当前稳定步骤。回到原场景恢复物件位置与状态，不重置正确构件。拖动中的物件可回到原候选位置，不视为完成。未完成声部播报可停止，不要求从开场重听。

E02 完成条件：结构完成、共鸣已处理。E03：摆碗完成、技艺已习得、共鸣已处理。E04：显纹与拓显完成、共鸣已处理、结果可查、主动敲鼓已完成，随后结算与章末扩容完成。每个事件只记完成一次；确认取舍后尚未敲鼓不能提前结算或扩容。

## 8. 章节验收清单

1. 去掉右侧长解释，玩家仍能通过榫口与记号找出左右件和方向。
2. 同一场景前后柱、门、梁、碗位置一致；梁稳之后可看见旧拼接痕。
3. 缺损件可以检查但不能正确安装，错误不丢已有进度。
4. 侧厢至少三个不同有效落点都能摆碗成功；檐外与重叠落点不能误通过。
5. 鼓面显纹明确发生在鼓面，三个拓显区域都需达到 65%；指针在外乱涂不能通过。
6. 点击选件、点击槽口和辅助显影都能完成，不依赖精细拖动。
7. 标准路径在 E04 出现 3/3，处理之后才扩为 3/4。
8. 四种取舍结果全部可复现；旧物件的真实修复不随归档消失。
9. 主动敲鼓总能听到正常鼓声，是否有专属童声严格由回春鲜活状态决定。
10. 全流程没有记忆价值评分、付费重试、静态谜题扣侵蚀或重复强制长失败对白。
11. 已确认选择后退出重启，不能再次领取或换回刚才归档的记忆。
12. 一位初次玩家能说明“留下了什么证据，放下了哪个回应”；无法说明时应修订反馈，而非先增加世界观文字。
