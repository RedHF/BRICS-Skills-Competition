# 美术与声音制作任务书

版本 v1.0，2026-11-02。用于 Codex 直接组织参考、生成、修订、接入与检查。范围 A/B/C 及玩法规则见 [00-改版总方案](./00-改版总方案.md)，场景逻辑见 [01-社庙代表章节详细设计](./01-社庙代表章节详细设计.md)。本文件不表示资产已生成。

## 1. 固定视觉方向

方向名：**纸上古建，墨中人间**。

环境沿用现有偏写实的水墨古建结构、木纹、旧墙与景深；边缘保留干湿墨变化，细节集中在交互部位。人物保留封面成年拓印师的身份、服装和笔册，统一实机比例；收藏沿用现有拓片。暖色落在人的使用痕迹与回应上。

2026-11-02 用户补充约束：新美术尽量与现有素材保持一致，避免深绿色素材。已重新查看 material/Example1.jpg、Example2.jpg、欢迎封面与正殿原图；以原有宣纸、墨刷、灰黑山水、朱红和暖金为基准，不以偏深绿的新配色替代既有风格。生图采用现有资产参考编辑，先局部修订再决定是否替换。

现有收藏图作为质感锚点，社庙正殿、侧厢、前坪作为空间底稿。制作基准板时并排放入：一段环境、一只碗、一块榫件、成年主角、拓片、对白底板和按钮。先通过这一页的整体一致性，再批量制作。

### 1.1 色彩基准

以下为新设计色值，不是现有素材实测值。最终依据实机对比调整。

| 用途 | 色值 | 规则 |
| --- | --- | --- |
| 纸底 | #E9E0CA | 界面主体，纹理低对比 |
| 主墨 | #302C28 | 中性暖墨，结构、正文、主要轮廓；不偏深绿 |
| 次墨 | #746B60 | 中性暖灰，远景、辅助结构，不能替代正文对比 |
| 旧木 | #76614B | 材料基调，同一物件前后保持 |
| 朱色 | #A64A3B | 交互印记与重要标识；有文字或形状同时提示 |
| 回应暖色 | #C59A55 | 碗影、灯影、手影出现的局部，不整屏泛黄 |
| 白蚀 | #D8D8CF | 配合截断轮廓、颗粒缺口；不能只靠浅色表达 |

UI 文字使用实色清楚底板。墨刷纹理不穿过关键字。普通、悬停、按下、不可用四态优先用同一组件的明暗和位置变化，避免每个状态单独生成一张不一致图片。

### 1.2 角色锁定

同一位成年拓印师，约七头身的简化比例；黑灰外袍、浅色内袖、谱册与长笔，朱色小绳结作为识别点。不做精致面部表演，面部不承担交互信息。

单方向加镜像即可。A 版最多三种定稿姿态：站立、行走关键姿态、抬笔；受击、闪身用短位移与墨影表达。人物高约占场景可行走区域高度的 28%—34%，以实际透视调整；不同深度区域按脚底位置缩放，不能把角色固定贴在同一大小的屏幕平面。

新比例没有通过前，正式片段可以暂用统一墨色轮廓；不得把写实新站姿与旧 Q 版攻击帧交替播放。封面可保留题字与环境，人物局部同步到定稿形象。

## 2. 空间连续性与状态分层

每个空间先确定一张母图、一个相机视角和交互坐标，再编辑状态。主柱、门、梁、碗、鼓在不同状态的位置误差不得导致热点落空；同构图叠放检查时，固定建筑边缘应重合。

运行中状态由四层组成：

1. 母图：不因个人记忆选择变化的建筑与真实物件。
2. 修复层：梁架倾斜／稳定、鼓面遮蔽／显纹、真实碗的位置。
3. 共鸣层：手影、灯影、第二只碗的记忆暖影、孩子跟拍对应微光。
4. 界面层：当前目标、选择和提示。

归档只改变第 3 层及其声部。修复后的梁、摆好的真实碗和可使用的鼓都不恢复破损。白蚀与留白另作处理：白蚀切断本来存在的纹样；留白保留完整纸面，不做噪点侵蚀。

### 3.1 A 版制作上限

优先沿用三张母图、四张已有收藏图与现有纸面组件。首轮独立图像生成最多六个目标：风格基准中的人物、人物三姿态必要补图、正殿局部、侧厢空碗、鼓面纹样必要补图。其余优先参考编辑、裁切、遮罩与组件处理。

每个目标首轮最多两个候选，最多两轮针对性修订；不能因为一个局部不理想反复重画全场景。两轮后仍不可靠时，使用清楚的简化墨色形体或既有资产，记入缺口，不拖住整个章节。

## 5. 生成与编辑的具体任务模板

生成时把“本轮采用的原始参考、需要保留的构图、需要改变的局部”与提示一起传入。不得只用“国风、水墨、高质量”等风格词让模型重新设计全部内容。

### 5.1 公共风格约束

> 用于《檐下千秋》的交互游戏资产。成年比例、克制的中国水墨淡彩，纸纤维与干湿墨变化，结构清楚，少量朱色与暖赭色强调人使用过的痕迹。保持参考中的建筑轮廓、透视、物件位置与材质。画面重点是明确指定的交互物件，背景细节压低。不要新增文字、界面、标志、水印、人物群像或额外建筑。不要改变已指定构件的凹凸轮廓和槽口数量。

这段属于制作提示，不进入产品内说明。

### 5.2 正殿局部任务

> 基于已选正殿母图，编辑梁端修复区域。保留主柱、侧门、地面旧碗与相机位置。制作同一梁架的两个状态：左端略倾、连接中断；连接完成、梁稳定但旧拼缝仍可见。左右接件的轮廓使用所附确定形状，不自由重设计。真实临撑位于梁下，能独立显示或移除。稳定后雨水不再落向碗沿，仍保留檐外雨水。输出不含提示字和编号，透明图层与母图对齐。

### 5.3 侧厢任务

> 同一侧厢门槛，门外湿、门内干。保留原有旧饭碗与蓑衣。增加一只可独立移动的空陶碗，透视匹配地面；碗可放在檐下而不遮挡旧碗。另做极淡的记忆暖影，暖影属于往事、可以独立消失，真实碗不消失。不要新增食物或把冷饭画成丰盛宴席。

### 5.4 鼓面任务

> 基于已选前坪母图的同一社鼓，锁定鼓身轮廓与朝向。鼓面的白蚀表现为旧纹样被截断，显纹后恢复可读的外环、中央纹与旧修补线；旧修补线仍保留。三处记忆图纹应能分别作覆盖遮罩。不要创造不属于该鼓面的浮空石碑，不新增文字，不重新设计背景树木。

### 5.5 主角任务

> 参考封面同一拓印师，成年约七头身，衣服和道具一致。降低面部与布料写实细节，强化简洁墨色轮廓，使其能放入水墨古建空间。三种姿态为站立、向侧前行一步、抬笔指向构件。保持头部比例、袍长、谱册位置、长笔长度与脚底锚点一致；完整身体、笔尖与双脚不裁断，真实透明背景。不要 Q 版化，不增加武器与配饰。

### 5.6 人工判断与修订依据

Codex 逐张检查：结构是否可读；答案形状是否保持；人物身份和比例是否一致；交互区是否有空位；固定物件是否漂移；透明边缘是否正确；旧痕是否保留。先修影响交互的错误，再修局部美观。生成候选不能直接当作已采用资产。

## 6. 文件与版本交付

每个资产包包含：原始参考、初始提示、原始候选、采用/拒绝理由、编辑成品、运行版、实机检查图。来源记录使用“工具、实际模型、日期、输入参考、修改目的”，不把聊天平台名当作图像模型。

运行版用稳定 ID；示例命名：`temple_hall_master`、`temple_beam_repaired`、`join_l`、`drum_reveal_outer_mask`、`echo_ning_an_warm_layer`。原始文件不可被运行压缩版覆盖。

纹理尽量不烘焙正文、答案名、容量数字或按钮文字。透明物件必须有真实透明通道，棋盘格不能画进像素。交付时附锚点位置、显示比例、状态前置与绑定对象。多状态在同一画布坐标中输出。

## 7. 声音资产清单

### 7.1 新增配音

严格使用 01 文件中的 VO-01—VO-12，最多 12 条。声部分为社庙、檐下谱、客声、童声四种；先核对已有参考音色，再选择能够复用的方案。实际调用工具与可用模型在执行时确认，不能在此假定某个未验证的服务一定可用。

若新增语音工具不可用或音色两轮仍不一致，A 版用完整字幕配合环境声，并静音冲突旧句；记录为“文字演出”，不伪称新语音已接入。这个降级不影响选择和谜题的可玩性。

### 7.2 短音效与环境声

| Cue | 内容 | 触发与退出 |
| --- | --- | --- |
| SFX-01 | 木件轻碰 | 候选选中，短一次，不盖住人声 |
| SFX-02 | 榫件扣合 | 正确安装，每件一次 |
| SFX-03 | 不合的轻碰 | 错误位置，温和提示，无刺耳失败音 |
| SFX-04 | 临撑落地/撤开 | 对应两动作可复用同一素材不同轻重 |
| SFX-05 | 碗触地 | 空碗有效落位一次 |
| SFX-06 | 纸页拓显 | 有效移动时短片段，停止动作即淡出 |
| SFX-07 | 正常社鼓声 | 主动敲鼓；回春归档后也能播放 |
| SFX-08 | 谱页翻合 | 确认归档或展开容量，不同速度复用 |
| SFX-09 | 远处锣回应 | 社庙章末一次，指向下一章 |
| AMB-01 | 檐外雨 | 三处环境共用，室内外调比例 |
| AMB-02 | 屋内空响 | 正殿/侧厢，稳定低强度 |
| AMB-03 | 前坪风与树叶 | 前坪底层，不自动混入专属童声 |
| ECHO-01—04 | 前四段专属回声 | 优先复用现有记忆音频；是否可播由鲜活状态决定 |

以上是 9 类短音效、3 类环境底声与4个既有回声绑定，不要求 16 次独立生成。可用既有素材先试听、处理、再复用。

### 7.3 混音规则

相对音量初始值：主对白 1.0、关键操作 0.55、环境 0.30、配乐 0.18。对白开始时配乐在 0.25 秒内降到 0.08，对白结束在 0.6 秒内回到 0.18；这些是调试起点，最终以实际扬声器试听为准。

一时只播一个主要人声；主动试听可以中断当前回声；切场景停止旧声，不堆积排队。归档在约 1.2 秒内退出对应声部，其他环境继续。静音与音量控制作用于所有新增声音。无声模式下仍能从文字和图层辨认结果。

## 8. AI 工作流证据

A 版至少保存两个完整真实案例：

1. 构件从“漂亮但不相合”到“凹凸轮廓可读”的修订，展示约束图、失败候选、采用图、实机拖放。
2. 同场景修复前后的位置校正，展示母图、局部编辑、叠放检查、最终状态变化。

如果某类失败没有真实发生，不为了答辩补造失败过程。记录真实的采用与调整即可。每个案例都说明“为什么这样改，以及玩家因此能做什么”。

## 9. 质量检查

- 以 1280×720 实机画面检查对象，离开原始高清图后仍能辨认榫口和缺损。
- 叠放状态图，固定建筑边缘重合；热点不因图层裁切变化而漂移。
- 查看透明通道与深浅底预览，确认无棋盘格、白边、断笔和裁脚。
- 检查角色定稿与实际三姿态，禁止旧 Q 版帧混入新比例。
- 关闭朱色后仍可凭形状和文字完成谜题；关闭声音仍可理解选择后果。
- 归档一段回声后，真实物件不消失；重新进入场景不触发已归档专属声部。
- 实际录屏与截图来自最后发行版本，不能用参考图代替可玩状态。

## 10. 文化参考的使用边界

[故宫博物院“斗栱”词条](https://www.dpm.org.cn/lemmas/241374.html)用于核对基本构件语言；[北京石刻艺术博物馆的传拓介绍](https://bjstoneartmuseum.org.cn/CN/news/benguangonggao/2019/0521/318.html)用于核对“呈现已有图文”的交互方向。参考资料用于事实校核，不默认获得转载其图片的授权。

游戏化机关采用简化轮廓，构件的历史名称只有在图形与依据一致时才写入图录；不确定时使用功能描述。“记忆鼓纹显影”明确为幻想交互，不宣称模拟真实鼓面传拓或真实建筑施工。
