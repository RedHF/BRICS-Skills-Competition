# 回响版：人工测试前设计定稿候选

日期：2026-11-05。状态：设计文稿已修订，等待初见体验验证。程序基线为 A13／A-preview13b；本文没有改变该程序。以下“定稿”锁定本轮表达和评估方式，不表示所有版式、文案已接入实机。

本文件收紧 00—04 中的主题表达、提示层次、选择版式和材料表述。现行容量、存档、判定及实现范围仍按 00 与 05 所记录事实读取。B/C 计划继续属于后续。

## 1. 可以直接用于新版策划正文的概述

《檐下千秋》是一款面向喜爱国风故事与轻解谜玩家的单机叙事冒险。玩家沿着廊桥、社庙、戏楼、牌坊和墨塔，观察人们留下的磨损、拼缝和生活物件，修复仍能被使用的空间，再决定让哪些独特往事继续随身回应。

游戏区分已经留下的记录、主角练会的手艺，以及能够被亲身唤起的回声。前两者不会因为归档而消失；心舍只承载有限的鲜活回声。每次显影，玩家可以带走，也可以只留记录。空位不足时，带走新回声需要放下一段旧回应。选择不会改变通关资格，也没有善恶分数。

社庙是当前重点章节：接梁让共同修屋的痕迹重新连起，摆碗为后来者留一个位置，显出鼓纹后的一次敲鼓，让玩家看到真实用途与私人回声的区别。作品希望玩家从具体物件中理解古建与人的关系；这种理解和取舍的情感效果尚待真人体验验证。

一句话介绍：**修好还能被使用的屋檐，决定哪些往事继续随身回应。**

## 2. 本轮保持的规则

| 项目 | 测试基线与设计约束 |
| --- | --- |
| 容量 | 初始 3 格；E04 完成后 4 格；E08 完成后 5 格；九段共鸣各一格，终章谱页不占格 |
| 首次满额 | 一路收录时在 E04 发生；主动归档者按实际容量，不承诺人人必然遇到同一种困境 |
| 归档 | 保留摘要、拓片、选择事实和修复；停止主角随身唤回该段专属完整回应 |
| 技艺 | 修复练会后保留；任何合法选择都不导致缺技能而无法继续 |
| 评价 | 不对取舍、提示使用和听觉能力评分；没有标准情感答案 |
| 重访 | 查看原选择，不覆盖旧旅程；已确认的归档不可靠重进撤回 |
| 容错 | 静态操作错误给局部原因，不清空正确步骤；鼠标、键盘与辅助显影完成地位相同 |
| 范围 | 五章十任务流程已有；社庙三段重点改版，其余章节没有全部按 C 版重制 |

“不能再次随身唤回”是游戏内能力约定，不宣称真实数字记录不能复制，也不以禁止玩家截图录屏补强世界观。普通环境声、实际鼓声与必要操作反馈不属于被关闭的私人回声。

## 3. 社庙的三种节奏

```mermaid
flowchart LR
    A[接梁：比较形状与方向] --> B[梁稳了，旧拼缝仍在]
    B --> C[摆碗：给来客留位]
    C --> D[真实空碗留在檐下]
    D --> E[拓显：看见既有鼓纹]
    E --> F[比较回声，确认取舍]
    F --> G[亲手敲鼓，辨认回应]
    G --> H[章末扩容，前往戏楼]
```

接梁提供本章主要推理：榫口形状与刻痕对应，朝向需要比较。第一次承架可以直接教，不把安全步骤变成猜谜。摆碗是一段轻量的生活回应，多个干地落点合法。拓显是一段观察与停留，不要求把纸面涂得漂亮；65% 是当前判定参数，不是玩家需要学习的文化知识。

三个段落各有一个主要动作。不增加额外分数、品级或收集奖励。是否削减重复的强制调查，需要记录“已经理解并尝试行动，却被查看门槛挡住”的实际例子后决定。

## 4. 提示层次与可直接替换的文案

以下为**待接入文案**，测试 A13 时不要提前朗读给体验者。操作键可常驻，关于答案的说明只在主动提示中展开。

| 位置 | 修订后的文字 | 用途 |
| --- | --- | --- |
| 入正殿目标 | “让这根梁重新接稳。” | 说明目的，不列所有步骤 |
| 梁口近看 | “凹口的方向不同，边上留着两道短痕和一道斜痕。” | 呈现形状和物证 |
| 双短痕件近看 | “凸出的一端旁，有两道短刻痕。” | 不直接命令转向 |
| 中部件近看 | “两端都有凸出的接头。” | 让玩家自己对照目标轮廓 |
| 旧件近看 | “端头缺去一角，断面仍能辨认。” | 说明缺损，不把旧物写成废品 |
| 常驻操作 | “点击选件与榫口；R 转半圈，Esc 放回。也可拖动。” | 操作方式清楚可查 |
| 主动提示一 | “比较木件和梁口的边缘。” | 指向观察对象 |
| 主动提示二 | “相同刻痕指向同一处接合，再看凸口朝向。” | 提供关系 |
| 主动提示三 | “先承架；双短痕件转半圈接左口，斜痕件接右口，再接中部并撤撑。” | 主动请求后可给完整解法 |
| 梁稳之后 | “梁稳了，拼过的旧痕还在。” | 用途和修补同时保留 |
| 侧厢目标 | “给檐下再留一个位置。” | 允许多个合理落点 |
| 旧碗记录 | “碗沿磨得发亮，旁边有两双筷子。” | 只写看得到的事实 |
| 回声记录 | “客声讲起：那晚有人把碗推到他面前。” | 标明叙述来源 |
| 本次行动 | “你将空碗放进了檐下。” | 不伪装成历史复原证据 |
| 鼓纹目标 | “显出留下的旧纹。” | 区别显影与创作新纹 |
| 首次容量说明 | “心舍已满。带走新回声，需要归档一段；也可以保留现有回声。” | 两种方向同样明确 |

不新增整套配音。新字幕若没有意义完全一致的旧音频，使用清楚文本与环境声，不能拼接不对应的录音。未知史实不由生成模型临时补齐。

## 5. 回声比较页的定稿规格

这是对下一次界面修改的规格，**尚未替换 A13 页面**。若真人没有遇到比较障碍，可只采纳短文案，不必为版式重做而重做。

1. 顶部一句说明当前空位和两种合法方向。
2. 左侧为新回声，右侧为当前选中的旧候选；两侧同等大小的拓片、一个具体物件、一句经历、一个“看与听”入口。其余旧候选用同尺寸页签切换；比较前不自动替玩家选定旧候选。
3. 下方同级排列“带走新回声…”和“保留现有回声…”。前者未选旧候选时不可提交；后者明确只归档新回声，不暗示失败或放弃奖励。
4. 试听和预览是选择帮助，不设看完次数、时长或全浏览要求。退出预览保留当前候选。
5. 两种方向都只需一个最终确认。纸墨确认页继续保留明确返回、具体对象和保存结果；默认焦点为“再想想”。

以新回春与旧宁安为例：

| 方向 | 确认标题 | 结果必须说清 |
| --- | --- | --- |
| 带走回春 | “带走「社·回春」，归档「社·宁安」？” | 孩子的跟拍留在心舍；碗与待客记录仍在，那一夜客声不再随身回应 |
| 保留现有 | “保留现有回声，只归档「社·回春」？” | 原有三段不变；鼓仍能敲响，孩子那次跟拍不再随身响起 |

两种确认均标一行：“本次旅程确认后不可改选；记录、修复与手艺保留。”这行是新文案要求，不冒称 A13 已逐字显示。

## 6. 四种后果的设计核对

| 归档对象 | 必须保留 | 退出的个人回应 | 可用的确认方式 |
| --- | --- | --- | --- |
| 平安 | 桥、桥灯、修复与技艺 | 那次归人脚步及对应记忆微光 | 同一桥景局部前后对照，不能把桥画成废墟 |
| 承香 | 梁、拼缝、捐木记号 | 抬梁手影与那次号子 | 同构图中手影退出，梁保持稳定 |
| 宁安 | 实体碗及其已保存位置、待客记录 | 那一夜客声与记忆暖影 | 保持真实空碗，退出独立暖影 |
| 回春 | 可操作的鼓、鼓纹与正常鼓声 | 孩子独有的跟拍 | 再敲一次鼓，普通声仍响，私人声部不再接上 |

字幕要区分“鼓响”和“记忆中的孩子回应”，无声体验可从文字状态与光迹理解差别。辅助信息说明发生了什么，不替玩家规定应该感到悲伤。

## 7. 扩容暂不改值，列入首要测试

现行章末扩容需要验证信任感。主持人先询问选择后的自由解释，再让体验者自然继续，扩容后问“接下来你原本以为会怎样，现在有什么不同”。不能在体验前暗示“是不是被骗了”。

若多位初见者自发提出“刚才为何不等这一格”，下一版优先比较：把新增承载能力放在下一章完成一项实质行动之后，并在取舍前说明“继续旅程会有成长，已经归档的回应不会因此恢复”。这是待比较的设计，未实施；完整曲线还需重算后续选择密度。不能只把扩容动画挪远并宣称矛盾已解决。

## 8. 五分钟内能被证明的内容

讲述围绕一个代表章节：物件旧痕 → 一次有依据的修复 → 一次知情选择 → 一个具体后果。AI 部分展示一条有参考、候选、筛选理由、校正和实机结果的真实制作链。模型名和产量只作背景。

A11 录屏、PPT、两份 PDF 是历史同版材料；当前程序是 A13，主页已删除独立片段入口。历史视频要标版本与两个独立起点，不能在 A13 路演中指向不存在的按钮；需要现场体验时通过正常旅程进入目标段落。未经当前版本重新录制，不称所有展示材料已同步。
